# 常用业务词汇与系统缩写对照表

为统一发票云运营团队与销售、交付、伙伴协作时的沟通语言，规范以下专有名词与缩写：

## 一、三大产品版本对照

| 当前标准名称 | 历史曾用名 / 别名 | 版本代号 | 架构与适用场景 |
| :--- | :--- | :--- | :--- |
| **标准版** | 发票云标准版、SaaS标准版 | 2.0 / 3.0 | 针对中小企业的标准化轻量 SaaS 产品，即开即用，公有云部署。 |
| **AI星瀚** | 发票云旗舰版、星瀚旗舰版 | 6.0 | 面向大型集团与超大型企业，支持高并发、多组织多法人架构，主打私有云及大客户定制公有云。 |
| **AI套件** | 星空旗舰版、发票云星空版 | 1.0 | 深度集成金蝶云·星空基础平台及 ERP 账套上下文，面向中型成长型企业。 |

---

## 二、三大核心业务对象 (面向对象概念)

| 对象类别 | 英文简称 | 核心管理实体 | 对应业务痛点与场景 |
| :--- | :--- | :--- | :--- |
| **订单与权益** | **LTC / UTR** | **Order (订单) & Rights (权益/服务资产)** | 解决商业层面的提单、特批审核、第三方采购，以及出库后在系统中的**激活、延期、加量包扩容与退换**。 |
| **客户与租户** | **MCR** | **Customer (客户企业) & Tenant (系统租户)** | 解决企业主体层面的**开收票企业税号变更、税控盘更换、跨租户合并、租户注销停用**。 |
| **生态伙伴** | **MTR** | **Partner (ISV / 代理伙伴)** | 解决渠道伙伴层面的**准入加盟、保证金缴纳、专属订货、业绩激励核算与退盟解约**。 |

---

## 三、常用核心系统缩写

| 系统缩写 | 英文全称 | 核心用途与职能 |
| :--- | :--- | :--- |
| **KBC** | Kingdee Business Cloud | 金蝶集团销售与商务管理大平台，承载金蝶中国渠道各机构的分销/直销下单、合同报备与业绩结算。 |
| **EOP** | Enterprise Operation Platform | 发票云星瀚运营平台，运营人员用于管理租户、下发授权、配置税局通道、执行特批延期与用量监控的核心工作台。 |
| **UTR** | Use to Renew | 使用到续约，指客户从产品交付上线、日常使用直至合同续费的整个客户存续期运营。 |
| **LTC** | Lead to Cash | 商机到回款，指从销售线索、售前咨询、商务签约、订单下达到财务到款确认的交易端到端流程。 |
| **MCR** | Manage Customer Relationship | 客户关系与信息管理，指对客户企业纳税人身份、多法人抬头及系统租户主数据的维护。 |
| **MTR** | Manage The Relationship | 生态伙伴管理，指对外部 ISV 伙伴、直加盟代理商的全生命周期关系维护。 |
| **OTP** | Online Transaction Platform | 统一在线购买平台，支持客户通过线上轻量化自助选品并支付订购发票云服务。 |
