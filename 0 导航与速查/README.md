# 发票云运营管理知识库

> 本知识库面向发票云运营团队及协同销售、交付伙伴，采用**面向对象业务架构**，清晰划分为“业务交易与权益（LTC/UTR）”、“客户与租户（MCR）”和“生态伙伴（MTR）”三大支柱。

---

## 知识库三大管理对象支柱

* **1 业务交易与权益履约（LTC/UTR）**【管理对象：订单 & 权益资产】
  - 承载售前支持、金蝶中国与自营双渠道提单、提前开通特批、第三方硬件采购合同，以及出库后的租户激活、特批延期、加量包扩容与退换排错。
* **2 客户与租户信息管理（MCR）**【管理对象：企业客户 & 租户实体】
  - 承载终端客户的租户权益查询、开票与收票企业税号/税盘变更、跨租户合并、租户停用与注销。
* **3 生态伙伴全生命周期（MTR）**【管理对象：ISV & 渠道伙伴】
  - 承载外部合作伙伴的准入加盟、保证金管理、专属订货折扣、业绩激励核算与退盟解约。
