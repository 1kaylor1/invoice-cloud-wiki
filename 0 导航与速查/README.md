# 发票云运营管理知识库

> 金蝶发票云运营团队核心业务知识库，沉淀 LTC 交易主线、MTR 生态伙伴、MCR 客户信息管理及跨环境系统授权操作规范。

---

## 知识库三大支柱与导航

* **0 导航与索引**：常用词汇字典、跨部门对接人速查、运营高频 FAQ。
* **1 商机到回款（LTC）**：
  - **1.0 业务全景与流程路由矩阵**：多维业务路由器，厘清渠道、版本与部署方式适用逻辑。
  - **01 金蝶中国渠道**：主干商业流（售前、合同、订单特批、正式交付与 UTR 激活、对账结算）。
  - **02 发票云自营渠道**：自营专属提单特批，通用交付环节内链引用主干（SSOT）。
* **2 生态伙伴管理（MTR）**：伙伴加盟、支持赋能、专属订货、激励核算与退盟退出。
* **3 客户信息管理（MCR）**：终端租户权益查询、税号与税盘变更、租户合并及注销停服。
