## 说明

本文档收录发票云运营Wiki中有歧义或同义的词汇，规定标准用词，避免混用造成理解偏差。

**写文章时遇到以下词汇，统一使用"标准用词"列的写法。**

## 业务概念类

| 标准用词 | 禁止混用的词       | 说明                            |
| ---- | ------------ | ----------------------------- |
| 伙伴   | 经销商、代理商、渠道商  | 统一称"伙伴"                       |
| 租户   | 客户账号、企业账号    | 统一称"租户"                       |
| 产品出库 | 发货、交付激活      | 订单收款确认后系统推送许可的动作，统一称"产品出库"    |
| 许可   | license、授权文件 | 旗舰版/星空旗舰版产品的授权文件，统一称"许可"      |
| 激活码  | 授权码、兑换码      | 客户激活产品用的凭证，统一称"激活码"           |
| 特批订单 | 特殊订单、例外订单    | 需要额外审批的非标准订单，统一称"特批订单"        |
| 临时许可 | 测试许可、试用许可    | 旗舰版/星空旗舰版产品测试用的临时授权，统一称"临时许可" |
| 测试授权 | 试用账号、演示账号    | 标准版产品测试用的授权，统一称"测试授权"         |

## 流程类

| 标准用词 | 禁止混用的词    | 说明                       |
| ---- | --------- | ------------------------ |
| 智能审批 | 审批流、流程审批  | 云之家中的审批系统，统一称"智能审批"      |
