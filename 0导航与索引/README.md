# 发票云运营知识库

> 金蝶发票云运营团队内部知识库，沉淀业务操作规范和流程指引。

## 知识库说明

**这是什么**：发票云运营团队内部知识库，收录业务操作规范、流程指引和常见问题解答。

**面向读者**：
- 发票云运营团队内部人员
- 金蝶中国渠道销售/伙伴
- 发票云自营渠道销售/伙伴

**三大业务板块**：
- **LTC（商机到回款）**：覆盖售前支持、合同管理、订单管理、产品交付、回款结算，分金蝶中国渠道和发票云自营渠道两套流程
- **MTR（生态伙伴管理）**：覆盖发票云自营伙伴和金蝶中国生态伙伴的全生命周期管理
- **MCR（客户信息管理）**：覆盖租户信息变更和租户权益查询

**文章类型**：
- `runbook`：操作类，照着步骤执行
- `explainer`：说明类，了解背景规则和分类逻辑

**AI 使用指引**：
- 通过每篇文章的 description 快速判断相关性，无需打开全文
- 遇到联系人/对接人问题，优先查看「内部对接人速查」
- 遇到术语歧义，优先查看「术语表」
- 遇到高频客户问题，优先查看「高频问题解答（FAQ）」
