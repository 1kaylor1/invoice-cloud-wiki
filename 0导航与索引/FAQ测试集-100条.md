## 一、产品体系（15条）

| # | 问题 | 答案 |
|---|---|---|
| 1 | 发票云有哪几条产品线？ | 开票管理、收票管理、影像管理三条产品线。 |
| 2 | 每条产品线有哪些版本？ | 开票和收票各有标准版、旗舰版、星空旗舰版；影像只有标准版和旗舰版，没有星空旗舰版。 |
| 3 | 标准版和旗舰版最核心的区别是什么？ | 标准版是公有云部署，无许可和环境概念；旗舰版基于苍穹平台，支持公有云和私有云，有许可和环境的概念。 |
| 4 | 星空旗舰版支持公有云部署吗？ | 不支持，星空旗舰版仅支持私有云部署。 |
| 5 | 什么是苍穹平台？和发票云有什么关系？ | 苍穹（Cosmic）是金蝶的技术底层平台，旗舰版和星空旗舰版发票云都是基于苍穹开发的。 |
| 6 | 星瀚是什么产品？ | 星瀚是发票云旗舰版产品在内部系统和邮件中的代号，即"金蝶云星瀚"，指发票云旗舰版。 |
| 7 | 什么是流量包？ | 流量包是针对数电票开票量的补充购买机制。产品订单附带基础开票额度，用完后需另购流量包才能继续开票。 |
| 8 | 影像产品有星空旗舰版吗？ | 没有。影像产品只有标准版和旗舰版。 |
| 9 | 旗舰版和星空旗舰版的区别是什么？ | 星空旗舰版是旗舰版的升级版本，功能模块更多，含更多智能特性（如智能赋码、三单匹配等）。 |
| 10 | 什么是税盘？开票一定需要税盘吗？ | 税盘是税务局颁发的硬件设备，用于税控发票的签名和上报。开数电票（全电发票）不需要税盘，走网络直连税局；开税控发票需要税盘。 |
| 11 | 数电票开票通道有哪几种？ | RPA（税务数字账户）、乐企自用、乐企联用三种。RPA接入快（3-5天），乐企对接效率更高但申请周期长。 |
| 12 | 发票云支持哪些ERP对接？ | 金蝶自家ERP（苍穹、星空）有标准对接方案；非金蝶ERP需走异构系统接口方式对接，需要定制开发。 |
| 13 | 什么是AI套件？ | AI套件是星空旗舰版里的智能功能模块，包含智能赋码、三单匹配等AI能力，需单独申请。 |
| 14 | 产品版本号6.0是指什么？ | 6.0是发票云旗舰版当前主推版本号，现有大部分旗舰版产品均为6.0版本。5.0是老版本。 |
| 15 | 发票云标准版部署方式是什么？ | 标准版仅支持公有云部署，不支持私有云。 |

## 二、渠道与下单（15条）

| # | 问题 | 答案 |
|---|---|---|
| 16 | 发票云有哪些销售渠道？ | 两大渠道：发票云自营渠道（直销+分销）和金蝶中国渠道（机构直销+伙伴分销）。 |
| 17 | 金蝶中国渠道和发票云自营渠道的下单系统分别是什么？ | 金蝶中国渠道在KBC系统下单；发票云自营渠道在EOP系统下单。 |
| 18 | 什么是KBC系统？ | KBC是金蝶中国渠道的下单系统，金蝶中国机构的直销和分销订单均在KBC中操作。 |
| 19 | 什么是EOP系统？ | EOP是发票云自营渠道的运营平台，用于订单管理、合同管理、产品出库、租户管理等操作。 |
| 20 | 什么是第三方询价合同（非标合同）？ | 非标合同是指产品未在KBC上架、需要单独询价签署的合同，走EOP非标合同流程，通常为后付费结算。 |
| 21 | 什么是后付费？和预付费有什么区别？ | 预付费：先付款再出库激活；后付费：先出库激活再结算付款。第三方采购订单通常为后付费。 |
| 22 | 金蝶中国渠道的分销下单和直销下单有什么区别？ | 直销是金蝶中国机构直接在KBC下单；分销是通过金蝶中国授权的伙伴在KBC下单。 |
| 23 | 在EOP里看不到KBC下的分销订单，正常吗？ | 正常。KBC渠道的分销订单在EOP的可见性取决于数据同步，目前交付操作在KBC星瀚侧完成，EOP看不到不影响交付流程推进。 |
| 24 | 什么是合同别（新购/续费/加购）？ | 按交易性质分类：新购=首次购买；续费=到期重购同类产品；加购=在有效期内增加税号数量或产品模块。 |
| 25 | 什么是加站加模？ | 加站指增加税号（站点），加模指增加功能模块。两者合称"加站加模"，均属于加购场景。 |
| 26 | 如何判断第三方询价订单归属哪个RBU负责人？ | 可以通过查看RBU名册，根据区域对应关系找到负责人。华南区总负责人为杭祖庆，深圳为曹燕等。 |
| 27 | 订单类型按合同形式分有哪几种？ | 标准订单（KBC上架产品直接下单）和特批订单（非KBC上架或需特殊处理，走审批流程）。 |
| 28 | 什么是TR费用？ | TR（Technical Resource）即技术资源费/实施服务费，是客户购买发票云实施交付服务的费用，和产品费是两笔独立费用。 |
| 29 | 合同有效期和许可有效期必须一致吗？ | 是的，合同要和系统一致，按实际签署。系统里许可激活到哪天，合同就签到哪天，不需要凑整年。 |
| 30 | 自营渠道下的收票旗舰版公有云试用流程有几步？ | 三步：申请智能审批→产品激活（许可分配）→获批测试环境（登录测试环境地址配置）。 |

## 三、许可与激活（15条）

| # | 问题 | 答案 |
|---|---|---|
| 31 | 发票云许可有哪几种类型？ | 临时许可（带水印，用于演示）、测试授权（无订货，仅限体验/联调）、正式授权（生产数据，原则上禁止随意申请）。 |
| 32 | 标准版产品有许可的概念吗？ | 没有。标准版没有许可和环境的概念，只有公有云授权，激活后直接使用。 |
| 33 | 标准版产品激活后客户如何使用？ | 标准版审批通过后系统发送激活邮件到预留邮箱，客户按邮件指引完成激活即可使用。 |
| 34 | 旗舰版公有云产品怎么激活？ | 审批通过后发送激活邮件，客户点击邮件链接→输入密钥验证→维护企业信息→分配许可。 |
| 35 | 旗舰版私有云产品怎么激活？ | 审批通过后发送激活邮件，客户完成许可分配后，还需登录cloud.kingdee.com激活下载.lic许可文件，上传到MC平台才能使用。 |
| 36 | 影像旗舰版私有云激活后系统显示"未启用"是什么原因？ | 许可分配完成后，客户还需登录cloud.kingdee.com下载.lic文件并上传到MC平台。未上传前系统显示"未启用"，不影响分配结果，是客户侧尚未完成激活操作。 |
| 37 | 收票旗舰版/星空旗舰版测试授权需要配置全电通道吗？ | 需要。收票产品必须配置电子税局账号才能从税局同步进项发票，这一步是测试授权流程的第四步。 |
| 38 | 什么是电子税局账号配置？ | 客户登录微信公众号【无忧演示300】，通过电子税局配置功能绑定电子税局账号，完成后收票产品才能从税局拉取发票数据。 |
| 39 | 激活邮件发给谁？ | 发给申请智能审批时填写的邮箱地址，即申请人预留的邮箱。如未收到请等待30分钟，或联系在线客服重发。 |
| 40 | 产品出库许可分配时，多个产品需要分别操作吗？ | 是的。许可分配时需要对每个产品逐一点击"去分配"并勾选企业，才算完成该产品的许可分配，否则对应产品不会生成授权。 |
| 41 | 许可分配后只勾选了企业但没有点"下一步"，会完成分配吗？ | 不会。系统不会实际扣减产品使用许可数量，必须完成勾选后点击【下一步】才算完成分配。 |
| 42 | 什么是授权账号、授权密钥、加密key？ | 这三个是ERP与发票云接口对接的API凭证，在产品出库许可分配完成后可查看。导出或展示时必须隐藏这三个字段，不得外传。 |
| 43 | 测试授权和正式许可有什么区别？ | 测试授权是没有订货的体验环境，仅供功能体验或联调，不产生真实业务数据；正式许可是生产授权，业务数据为真实数据。 |
| 44 | 测试授权申请累计最长多少天？ | 金蝶中国渠道：默认1套，累计不超过60天（单次最多30天）。 |
| 45 | 测试授权和交付流程有什么不同？ | 测试授权只配置测试通道，不做正式税局通道配置，不走完整交付验收流程；正式交付需配置正式税局通道、跑通后验收，流程更完整。 |

## 四、特批流程（15条）

| # | 问题 | 答案 |
|---|---|---|
| 46 | 什么是特批订单？适用于什么场景？ | 特批订单是走审批流程的订单，适用于产品提前开通（合同/付款在途但需先开通）等非标准流程场景。 |
| 47 | 标准版产品特批延期申请入口在哪里？ | 云之家 → 智能审批 → 金蝶发票云（标准版）产品特批延期申请。 |
| 48 | 旗舰版产品特批延期入口在哪里？ | KBC → 销售管理 → 合同 → 延期续签申请。不走云之家智能审批。 |
| 49 | 标准版特批延期申请需要填哪些信息？ | 签约客户名称、目标租户、客户联系方式、延期原因、产品明细（企业/税号/起止时间）。 |
| 50 | 特批延期审批通过后，续费时到期时间怎么计算？ | 续费仍按原有产品到期时间计算，不是从延期后的时间起算。延期只是临时延长使用，不改变续费基准时间。 |
| 51 | 同一客户同年最多可以申请几次特批延期？ | 最多3次，每次都需要向发票云对接人说明原因。 |
| 52 | 特批延期和正式续费有什么本质区别？ | 特批延期是临时保住权益不中断的措施，不产生新订单；正式续费是重新购买，产生正式续费订单。两者最终都需要走续费流程。 |
| 53 | 什么是标准版正式许可特批？适用场景是什么？ | 经发票云总经理或运营特批后，直接给客户开通正式许可，跳过订单流程。门槛极高，日常很少用到。 |
| 54 | 产品特批订单申请和标准版正式许可特批是一回事吗？ | 不是。特批订单申请是走特批流程创建一个新购订单；正式许可特批是跳过订单直接给许可，是两个完全不同的流程。 |
| 55 | 特批订单申请的典型场景是什么？ | 最典型的是提前开通场景：客户合同/付款在途，需要先开通产品使用，后续再补齐付款手续。 |
| 56 | 特批时间最长可以申请多少天？ | 知识库中记载特批延期单次最多30天，累计不超过60天。正式许可特批无明确次数限制，但需要总经理/运营授权。 |
| 57 | 特批订单审批通过后EOP会生成什么？ | 系统会创建虚拟单延长客户使用时间，不是正式续费订单。 |
| 58 | 多租户场景下，客户续费遇到配置问题可以走特批吗？ | 可以作为临时解决手段，但建议优先走正常下单流程，向售后提供多租户企业信息由售后配置，避免消耗特批次数。 |
| 59 | 发票云旗舰版和星空旗舰版的提前开通测试授权，金蝶中国渠道走什么流程？ | 在KBC申请临时许可，再走云之家智能审批测试授权流程，最后完成产品激活和全电通道配置，仅支持私有云。 |
| 60 | 特批审批通过后没有收到激活邮件怎么办？ | 先等待30分钟，检查垃圾邮件；若仍未收到，联系在线售后客服：https://tax.piaozone.com/sobot-web/home |

## 五、客户信息与租户管理（15条）

| # | 问题 | 答案 |
|---|---|---|
| 61 | 租户和企业是什么关系？ | 租户是系统容器，企业是租户内绑定的具体主体（按税号标识）。一个租户可以包含多个企业。 |
| 62 | 租户合并和企业变更租户有什么区别？ | 租户合并：A租户合并至B，A停用，权益全部迁移到B；企业变更租户：只将特定企业从A迁到B，A租户本身不停用，原权益自动失效需重新绑定。 |
| 63 | 租户合并后数据会自动迁移吗？ | 租户合并会自动迁移权益，业务数据迁移需要变更双方同意，如需迁移要在申请时注明。 |
| 64 | 企业变更租户后，原来分配的产品权益还有效吗？ | 无效。企业变更租户后原租户下分配的产品权益自动失效，需在新租户下重新绑定有效订单权益。 |
| 65 | 申请租户合并需要提供什么材料？ | 至少一种客户授权证明：加盖公章的书面申请、包含变更信息的邮件记录、或其他能体现客户同意的文字沟通记录。 |
| 66 | 租户合并操作入口在哪里？ | 云之家 → 智能审批 → 企业变更租户/合并租户申请流程。 |
| 67 | 特批订单在有效期内走租户合并，数据能迁移过去有效吗？ | 可以。只要合并时源租户的权益处于有效状态，迁移过去的权益就是有效的。必须在特批有效期内完成合并，失效后再合并则迁移过去的是已失效的权益记录。 |
| 68 | 如何查看一个租户是否走过合并操作？ | 在EOP中找到该租户详情页，点击左侧"租户变更记录"，可以看到历史上所有的变更和合并操作记录。 |
| 69 | 开票产品的企业税号变更入口在哪里？ | 云之家 → 智能审批 → 发票云开票产品使用企业名称&税号&税盘变更申请。审批通过后即时生效，原有企业将无法使用，请务必核实信息再提交。 |
| 70 | 收票产品的使用企业信息变更入口在哪里？ | 云之家 → 智能审批 → 金蝶发票云实施激活企业信息变更审批流程。 |
| 71 | 什么是租户权益查询平台？ | cosmic-pro.piaozone.com，可查询订单明细、许可有效期、企业绑定、流量耗用等信息。账号通过邮件获取。 |
| 72 | 如何查询某个客户的开票流量剩余情况？ | 登录租户权益查询平台（cosmic-pro.piaozone.com），搜索对应租户查看流量耗用情况。 |
| 73 | 客户反映开不了票了，可能有哪些原因？ | 常见原因：1）流量包用完；2）产品许可到期；3）测试通道未切换到正式通道；4）税盘问题；5）系统异常。 |
| 74 | 授权账号、授权密钥、加密key在哪里查看？ | 在产品出库许可分配完成页面，点击"获取下单租户下企业授权信息"→"立即查看"可查看。这三个字段属于敏感信息，不得外传。 |
| 75 | 一个企业多个租户使用产品，怎么处理？ | 正常下单，向售后提供需要挂多租户的企业信息，售后协助配置，不需要走特批。 |
