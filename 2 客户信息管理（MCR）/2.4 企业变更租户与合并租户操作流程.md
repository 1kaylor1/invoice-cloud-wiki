# 企业变更租户与合并租户操作流程

本文适用于已购买发票云产品的客户申请企业变更所属租户或租户合并，指导经办人完成类型选择、客户证明准备及审批提交，并说明变更后的权益处理。

## 申请前提

**必须取得客户有效授权或有效申请后，才能发起企业变更租户或租户合并。没有客户确认授权，不得办理。**

变更或合并会直接影响租户内权益所属及业务数据存储。申请前需确认变更对象、迁入与迁出租户，以及是否迁移业务数据；需要迁移业务数据时，必须取得迁移双方同意。

## 选择申请类型

| 对比事项 | 租户合并 | 企业变更租户 |
|---|---|---|
| 适用场景 | 将A租户合并至B租户 | 将企业从A租户改绑至B租户 |
| A租户状态 | 合并后停用 | 继续启用 |
| 权益处理 | A租户权益全部合并至B租户 | 企业解绑A租户下对应产品权益，变更至B租户后需自行绑定有效订单权益 |
| 企业明细 | 默认全部企业改绑，无需逐项填写企业信息 | 部分企业变更租户时，必须填写对应企业名称和税号 |
| 业务数据 | 已产生业务数据且有迁移需要时，支持同步迁移；须取得迁移双方同意 | 已产生业务数据且有迁移需要时，支持同步迁移；须取得迁移双方同意 |

例如，企业原先绑定了A租户下的开票产品，改绑到B租户后，原来分配的开票产品权益自动失效，需要在B租户下重新绑定有效订单权益。

## 操作步骤

### 第一步：准备客户申请证明

准备能够体现客户有效申请或授权的证明材料，包括但不限于加盖公章的材料、邮件信息、文字沟通记录或企业组织关系证明。证明材料应体现变更前后企业或租户的完整信息。

可参照审批表内的 **“企业或租户变更申请模板.docx”** 填写。附件名称：**企业或租户变更申请模板(1).docx**。模板填写内容包括：

- 申请企业全称、统一社会信用代码及申请原因。
- 申请“企业变更租户”时，填写企业名称、企业税号、变更前租户名称及变更后租户名称。
- 申请“租户合并”时，填写合并前租户名称及合并后租户名称。
- 按模板填写确认声明、企业名称、日期及公章位置。

【待补飞书附件链接：企业或租户变更申请模板(1).docx】

### 第二步：进入申请流程

进入 **云之家 → 智能审批 → 企业变更租户/合并租户申请流程**。

### 第三步：填写变更信息

| 字段 | 填写说明 |
|---|---|
| 申请类型 | 按办理场景选择租户合并或企业变更租户 |
| 变更/合并前租户名称 | 填写完整、准确的原租户名称 |
| 变更/合并后租户名称 | 填写完整、准确的目标租户名称 |
| 原租户是否已产生业务数据 | 核实原租户的实际情况后选择 |
| 是否需迁移业务数据 | 按客户确认的迁移需求选择；迁移须经双方同意 |
| 变更企业明细 | 部分企业变更租户时，填写企业名称和企业税号；租户合并默认全部企业改绑，无需填写企业信息 |
| 客户证明 | 上传第一步准备的客户申请或授权证明材料 |

![[98ad924c2caf8c816d19306fa9782a6a_MD5.png]]

### 第四步：核对并提交

核对申请类型、变更前后租户名称、企业明细、业务数据情况及迁移需求，确认客户证明完整且与本次变更一致后，点击“提交”。

## 变更后的权益衔接

- **租户合并**：A租户停用，A租户权益合并至B租户。
- **企业变更租户**：A租户继续启用，变更企业不再使用原绑定权益，需要在B租户下自行绑定有效订单权益。
- **业务数据迁移**：按经双方同意的迁移需求办理，不能以租户或权益关系已变更代替业务数据迁移完成的确认。
