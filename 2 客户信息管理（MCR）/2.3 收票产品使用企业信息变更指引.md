# 收票产品使用企业信息变更指引

本文说明收票产品使用企业的名称修改、税号纠正及产品使用权变更申请，办理终点为审批及对应变更处理完成。

## 适用场景与办理规则

**操作角色**：机构直销客户经营、分销管理、客户成功部。

| 办理事项 | 适用场景 | “更改类型”选择 | 申请规则 |
|---|---|---|---|
| 企业名称变更 | 修改产品使用企业名称 | 企业名称 | 每次提交一家企业的一项信息变更；名称和税号均需变更时，分别提交两次 |
| 企业税号纠正 | 纠正维护错误的企业税号 | 企业税号 | 每次提交一家企业的一项信息变更；名称和税号均需变更时，分别提交两次 |
| 收票产品使用权变更 | 同一组织下属企业A不再使用产品，将使用权转给企业B | 特殊变更（详情请表说明） | 默认每次提交一家企业的信息变更；涉及两项以上时，另附变更明细表，走人工处理 |

## 操作步骤

### 第一步：进入审批并选择更改类型

进入 **云之家 → 智能审批 → 金蝶发票云实施激活企业信息变更审批流程**，按本次办理事项选择“更改类型”。

### 第二步：填写共用信息

| 字段 | 填写说明 |
|---|---|
| 签约客户名称 | 填写下单客户名称 |
| 联系电话 | 填写管理员联系电话 |
| 产品序列号 | 填写需要变更的企业或税号绑定的产品序列号；企业名称或税号纠正涉及多个序列号时，用“、”隔开 |
| 企业税号 | 填写变更前使用企业的税号；税号纠正时填写当前维护的错误税号 |
| 企业全称 | 填写变更前使用企业名称 |
| 产品类型 | 选择实际使用的金蝶ERP类型 |
| 变更原因说明 | 说明本次变更原因；特殊变更应说明产品使用权转移事项 |

按页面标有“*”的必填项填写完整，再补充对应类型的新信息。

### 第三步：填写变更后的信息

#### 企业名称变更

“更改类型”选择“企业名称”，在“新企业名称”中填写变更后的企业名称。

![[b00790d2244678eda961de5050a4cd28_MD5.png]]

#### 企业税号纠正

“更改类型”选择“企业税号”，在“新企业税号”中填写正确的企业税号。

![[dfad5a1de95ade3ad17659627fcb9343_MD5.png]]

#### 收票产品使用权变更

“更改类型”选择“特殊变更（详情请表说明）”，填写需要转移使用权的产品序列号，以及变更前企业和接收企业的信息；在“新企业税号”中填写接收企业税号，并按实际变更情况填写“新企业名称”和变更原因。

涉及两项以上时，在附件中上传变更明细表，可按以下模板列明产品使用权变更前后的对应关系：

| 序号 | 产品序列号 | 变更前A企业名称 | 变更前A税号 | 变更后B企业名称 |
|---|---|---|---|---|
| 示例 | 1327685694545342 | 羊羊羊软件有限公司 | 24343253235RX15 | 兔兔兔软件有限公司 |
| 1 |  |  |  |  |

接收企业税号仍需在申请表的“新企业税号”字段填写。

**使用权变更示例**：同一组织下，A企业的收票产品于2023年6月6日到期，B企业已有的收票产品于2023年3月3日到期。A企业不再使用，将使用权转给B企业后，该示例中B企业的到期日变为2023年6月6日。

![[0522d3c989f53893338ef2173794a43e_MD5.png]]

### 第四步：核对并提交

核对产品序列号、变更前后企业名称及税号、产品类型和变更原因，确认必填项完整；特殊变更涉及多项时，同时核对附件明细，然后点击“提交”。需要继续补充时可先“存为草稿”。

## 审批与处理结果

企业名称变更和税号纠正按流程完成审批及处理；特殊变更走人工处理。以审批及对应变更处理完成作为办理完成点，暂存草稿或仅提交申请不代表已完成变更。
