# 租户权益与用量查询操作指引

本文适用于已收到租户查询平台账号的发票云租户用户，指导用户登录平台并查询当前租户的权益、订单及用量，也说明管理员状态维护和查询结果导出方法。

## 登录前准备

查询平台链接、登录账号及初始密码通过邮件发送。请使用实际收到的账号信息登录。

![[7e9973228e99edc8a44da52f8aac4b7e_MD5.png]]

首次登录需修改密码。请确认账号对应的手机号仍可正常使用并接收短信；手机号已停用时，先联系发票云售后修改用户信息。

## 进入租户权益看板

### 第一步：登录查询平台

打开邮件中的平台链接，或进入[租户查询平台](http://cosmic-pro.piaozone.com/ierp/login.html)，输入邮件中的账号和密码，点击“登录”。

![[fd16804c0d55916673e4bba5ac83d06c_MD5.png]]

### 第二步：打开运营管理应用

登录成功后，进入 **应用 → 运营管理**。

![[7f0b5ed0f9330c71c6458a29bc8bbaec_MD5.png]]

### 第三步：进入租户权益看板

在运营管理应用中，进入 **租户 → 租户权益看板**，查看当前租户的权益汇总。

![[7c2c65104f442c1dd56a30195eaf3f3e_MD5.png]]

![[ee1458e52525febe2ba8b85abd1d8d10_MD5.png]]

## 按需查询权益信息

看板提供租户基础信息、管理员账号、待分配交易订单、产品到期提醒、产品使用配置及流量耗用信息。按需要进入对应区域，无需依次操作全部模块。

![[52eb377fd418f38abcd67e3845edbfbd_MD5.png]]

### 查看租户详情

点击“查看租户详情”，查询租户名称等基础信息。

![[518e6f2e4009491a713f4116fa58139a_MD5.png]]

### 查看及维护管理员状态

1. 点击“修改管理员账号”，打开“租户管理员”窗口。
2. 查看管理员姓名、手机、邮箱地址及状态。
3. 如需调整管理员状态，选择“启用”或“禁用”，然后点击“确认修改”；不保存调整时点击“取消修改”。

**只有处于启用状态的管理员账号可以登录权益查看系统。**

![[008534e426ec1a4888a34e957c6cda3d_MD5.png]]

![[49ac6dd40ae110e265828616fbef4be7_MD5.png]]

### 查看尚未分配完成的订单

点击“交易订单统计”区域的“待分配”数量，打开待分配交易订单列表，查询已购买、在有效期内且尚未分配完成的订单。

一个交易订单可能包含多个产品。列表可查看交易订单编号、产品名称、产品订单编号、订购数量、未分配数量、许可到期时间及许可启用状态等信息。

![[b6a350c70017b007db30f1484c0cb64f_MD5.png]]

需要继续分配时，可从列表点击未分配的交易订单进入分配流程，将订单绑定到使用企业或税盘。

![[23169196de3d932e1aa8b18751eab7d3_MD5.png]]

### 查看产品到期及分配详情

在“产品到期续费提醒”区域，点击对应状态的数量，查看产品及分配详情：

| 查询入口 | 查询内容 |
|---|---|
| 60–90天内到期产品 | 对应时间段内即将到期的产品 |
| 30–60天内到期产品 | 对应时间段内即将到期的产品 |
| 30天内到期产品 | 30天内即将到期的产品 |
| 已过期产品 | 已经过期的产品 |
| 查看全部数据 | 当前租户下全部产品及分配信息，不按上述到期状态筛选 |

![[ebebc762206147d8ea60fa743b829a6e_MD5.png]]

在“租户产品分配详情”中查看产品序列号、许可到期时间、权益分配状态及绑定企业、税盘等信息。许可分配维度为税号且企业信息为空时，表示尚未绑定指定的使用企业和税号。

需要留存或分享查询结果时，点击“导出权益数据生成Excel表格”。需要续费时，获取对应产品序列号等信息后，联系机构销售人员协助办理。

![[336cd39321fb3adff15512ca3a75117b_MD5.png]]

### 查看产品使用配置信息

在“产品使用配置信息”区域，点击对应产品入口：

| 入口 | 查询内容 |
|---|---|
| 查看收票配置信息 | 已分配收票产品的企业授权信息 |
| 查看开票配置信息 | 拥有开票权益的企业、税盘信息 |
| 查看影像配置信息 | 已购买影像产品的业务配置信息 |
| 查看档案配置信息 | 已购买档案产品的业务配置信息 |

![[3f550376ea1a49e6ee602a1df1473f0e_MD5.png]]

### 查询流量耗用及扣减规则

在“租户权益耗用统计”区域查看票量、短信的已用量及剩余量，并点击对应的“查看耗用明细”。需要了解票量扣减方式时，点击“查看耗用规则”。

流量权益由租户下税号共享，包括识别查验票量、短信、存储服务等。未单独说明耗用规则的流量产品，按使用一次扣减一个流量单位计算，例如发送一条短信扣减一条短信数量；有单独耗用规则的，按对应规则核对。

![[aa7647b84805411c534939d94d8ff6a2_MD5.png]]

进入票量耗用统计页面后，可选择“统计区间”并点击“查询”，查看累计总票量、累计已耗用票量、剩余票量，以及租户下各企业的耗用信息。点击企业行的“查看耗用明细”可进一步查看明细，点击“导出列表”可导出查询结果。

![[6bccb84f49c132d0a93281c84dcb76c7_MD5.png]]

## 查询结果与售后支持

查询完成后，可获取对应订单、产品序列号、到期时间、分配情况或流量耗用数据，供续费、分配及用量核对使用。

登录、账号信息或权益查询遇到问题时，通过[发票云售后支持](https://tax.piaozone.com/sobot-web/home)获取帮助或反馈问题。
