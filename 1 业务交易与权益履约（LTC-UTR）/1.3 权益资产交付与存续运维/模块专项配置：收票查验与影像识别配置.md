# 模块专项配置：收票查验与影像识别配置

## 1. 适用场景

适用于正式交付或测试交付中，客户订购了收票管理（查验/抵扣）或进项发票影像模块时的系统后端通道初始化配置。

## 2. 前置准备

* 目标租户已完成创建并生效对应许可。
* 客户进项抵扣盘或电子发票综合服务平台证书已完成授权绑定。
* 运营已分配对应的 OCR 识别服务并发流量池。

## 3. 操作步骤

### 第一步：收票查验通道与底账库同步配置
1. 登录 EOP，进入 **收票管理 $\rightarrow$ 查验通道配置**。
2. 绑定客户企业税号与主管税局接口网关。
3. 配置自动底账拉取频度（如：每日夜间拉取 / 实时按需拉取）。
4. 在租户前台上传一张已开具的历史发票进行查验联调，验证发票状态（正常/作废/红冲）是否精准回传。

### 第二步：发票影像与 OCR 识别引擎配置
1. 进入 **影像服务管理 $\rightarrow$ 识别引擎通道**。
2. 配置默认 OCR 解析提供方（金蝶自研影像引擎或高精度外部通道）。
3. 设定自动纠偏、发票切边、防重发票预警阈值。
4. 测试上传 PDF 电子发票、拍照发票及扫描仪批量进纸，校验发票全票面结构化提取准确率。

## 4. 常见异常处理
* **验证码识别失败**：若税局查验平台触发强图形滑块，检查验证码智能打码服务通道是否欠费或可用额度为零。
* **OCR 解析无返回**：检查图片分辨率是否过低，格式是否受限（支持 JPG/PNG/PDF）。
