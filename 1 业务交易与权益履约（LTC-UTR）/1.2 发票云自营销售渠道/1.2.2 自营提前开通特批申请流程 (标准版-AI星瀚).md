# 自营提前开通特批申请流程（标准版 / AI星瀚）

本文介绍发票云自营渠道提前开通申请，办理至审批和结果接收。许可分配、产品激活与交付另行办理；测试申请参见[自营测试申请流程](<1.2.1 自营测试申请流程 (标准版-AI星瀚).md>)。

## 一、标准版提前开通申请

标准版开票、收票和影像通过云之家智能审批申请。开票、收票适用公有云；影像按实际申请公有云或私有云。

### 申请条件

- 标准版提前开通的特批时间不得超过 **30天**，须有签署中的合同文件支持。
- 书面承诺正式合同产品启用时间不晚于本次特批启用时间，且合同购买数量大于特批启用数量；否则额外产生的成本由对应机构承担。

### 第一步：填写并提交申请

1. 进入 **云之家 → 智能审批 → 金蝶发票云产品特批订单申请审批流程**。
2. 在【申请原因】中写明与客户签订协议约定的开始、结束日期，并承诺未按期订货造成的损失由机构承担；附件上传与客户签约的合同文件。
3. 企业全称及企业税号填写合同签约客户的信息；【用户数】填写使用产品的税号或税盘数量。填写申请起止时间、联系电话和能正常收信的邮箱，页面带星号的字段为必填项。
4. 按下表选择产品及部署方式，核对申请信息后提交审批。

| 申请产品 | 产品名称 | 部署方式及注意事项 |
|---|---|---|
| 标准版开票 | 开票管理（标准版） | 公有云 |
| 标准版收票 | 基础收票管理（标准版） | 公有云；无需选择发票校验流量包（标准版） |
| 标准版影像 | 电子影像服务，5.0 | 按实际选择公有云或私有云 |

例如，母公司 A 签约，为子公司 A1、A2 各申请一个开票或收票授权时，企业全称和税号填写母公司信息，用户数填写 2。

### 第二步：接收审批结果

- **标准版开票、收票**：审批通过后，系统向申请表填写的邮箱发送激活邮件。半小时内未收到时，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。
- **标准版影像公有云**：审批通过后，申请邮箱接收登录地址、账号和密码；密码为手机号账号后六位。
- **标准版影像私有云**：审批通过后，申请邮箱接收许可地址。

## 二、AI星瀚提前开通申请

AI星瀚开票、收票和电子影像提前开通支持公有云及私有云（订阅），通过云之家智能审批申请。

### 申请条件

- AI星瀚提前开通的特批时间不得超过 **30天**，须有签署中的合同文件支持。
- 书面承诺正式合同产品启用时间不晚于本次特批启用时间，且合同购买数量大于特批启用数量；否则额外产生的成本由对应机构承担。

### 第一步：填写并提交申请

1. 进入 **云之家 → 智能审批 → 金蝶发票云产品特批订单申请**。
2. 在【申请原因】中写明与客户签订协议约定的开始、结束日期，并承诺未按期订货造成的损失由机构承担；附件上传与客户签约的合同文件。
3. 企业全称及企业税号填写合同签约客户的信息；【用户数】填写使用产品的税号或税盘数量。填写申请起止时间、联系电话和能正常收信的邮箱，页面带星号的字段为必填项。
4. 按下表选择产品及部署方式，核对申请信息后提交审批。

| 申请产品 | 产品名称 | 部署方式 |
|---|---|---|
| AI星瀚开票 | 开票管理（旗舰版） | 公有云或私有云（订阅） |
| AI星瀚收票 | 基础收票管理（旗舰版） | 公有云或私有云（订阅） |
| AI星瀚电子影像公有云 | 电子影像服务（旗舰版）公有云，版本 1.0 | 公有云 |
| AI星瀚电子影像私有云 | 电子影像服务（旗舰版）私有云（订阅） | 私有云（订阅） |

例如，母公司 A 签约，为子公司 A1、A2 各申请一个开票或收票授权时，企业全称和税号填写母公司信息，用户数填写 2。

### 第二步：接收审批结果

- **AI星瀚开票、收票**：审批通过后，系统向申请邮箱发送激活邮件；半小时内未收到时，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。公有云的正式环境开通信息发送至租户联系邮箱；私有云通过许可生成通知邮件中的链接下载许可，链接有效期为 **30天**，请及时下载保存。
- **AI星瀚电子影像公有云**：申请邮箱接收登录地址、账号和密码；密码为手机账号后六位。
- **AI星瀚电子影像私有云**：智能审批通过后，联系 **周扬**获取许可文件。
