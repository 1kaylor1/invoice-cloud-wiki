# 自营测试申请流程（标准版 / AI星瀚）

本文适用于发票云自营渠道申请标准版和 AI星瀚开票、收票、电子影像测试，办理至审批结果及测试信息接收。后续许可分配、产品激活、环境配置和电子税局配置另行办理。

## 申请前确认产品和期限

| 测试产品     | 云之家产品名称                | 部署方式及申请要求                                            |
| -------- | ---------------------- | ---------------------------------------------------- |
| 标准版开票    | 开票管理（标准版）              | 公有云；数电票测试通道最多使用 **30天**                              |
| 标准版收票    | 基础收票管理（标准版）            | 公有云；无需选择发票校验流量包（标准版）                                 |
| 标准版影像    | 电子影像服务，5.0             | 累计申请时长不超过 **60天**，不可延长；开始时间选申请当日或以前的日期               |
| AI星瀚开票   | 开票管理（旗舰版）              | 公有云或私有云（订阅）；可使用星瀚自带虚拟 UKEY 测试，也可使用最多 **30天**的数电票测试通道 |
| AI星瀚收票   | 收票管理（旗舰版）              | 公有云或私有云（订阅）                                          |
| AI星瀚电子影像 | 电子影像服务（旗舰版）私有云（订阅），6.0 | 私有云（订阅）                                              |

标准版影像的部署方式请按申请页面及实际需求确认。

## 第一步：填写测试授权申请

1. 进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请审批流程**。
2. 在【申请原因】中说明测试需求。企业全称和企业税号填写合同签约客户的信息；【用户数】填写使用产品的税号或税盘数量。
3. 按上表选择产品名称和部署方式，填写开始时间、到期时间、联系电话和能正常收信的邮箱。申请标准版影像时，核对累计申请时长不超过 60 天且开始时间不晚于申请当日。
4. 核对页面带星号的必填项、日期和用户数，点击【提交】发起审批；需要暂存时可使用【存为草稿】。

例如，母公司 A 签约，为子公司 A1、A2 各申请一个开票或收票测试授权时，企业全称及税号填写母公司信息，用户数填写 2。

## 第二步：接收审批结果和测试信息

- **标准版开票、收票**：审批通过后，系统向申请表填写的邮箱发送激活邮件。
- **标准版影像**：审批通过后，测试登录地址和登录账号通过邮件发送，登录密码为登录账号后六位。
- **AI星瀚开票、收票**：审批通过后生成测试授权。公有云测试环境信息发送至租户联系邮箱；私有云许可生成通知邮件包含许可下载链接，链接有效期为 **30天**，请及时下载保存。
- **AI星瀚电子影像私有云**：智能审批通过后，联系 **杨慧莉**获取许可文件。

标准版开票、收票和影像，或 AI星瀚私有云开票、收票审批通过半小时仍未收到邮件时，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。AI星瀚公有云开票、收票未收到测试环境邮件时，也可联系在线客服。
