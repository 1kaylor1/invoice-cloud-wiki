# KBC渠道下单发票云换货流程（退货不退款）

本文说明 KBC 订货的发票云产品如何申请退货不退款，以及审批通过后如何重新订货换货。本流程也支持伙伴退货。

## 申请前确认

- **经办角色**：机构直销客户经营、分销管理、客户成功部。
- **产品范围**：仅限通过 KBC 订货的发票云产品。
- **激活限制**：同一序列号的产品已激活（包括部分激活）时，无法申请本流程。
- **准备材料**：准备合同及相关信息、退货处理报告和终止协议，以及申请原因所需的处理经过。

## 第一步：填写退货不退款申请

进入 **云之家 → 智能审批 →【直销】退货退款业务申请**，按实际情况填写表单中带星号的必填项：

| 字段 | 填写要求 |
|---|---|
| 客户名称 | 填写签约企业名称。 |
| 产品名称、产品版本号 | 填写或选择本次退货涉及的产品信息。 |
| 产品序列号及订单号 | 填写相应信息；没有时按页面提示填“无”。 |
| 系统合同编号 | 填写相关系统合同编号。 |
| 是否伙伴退货、服务是否开通 | 根据实际情况选择。 |
| 退款金额 | 填写 **0**。 |
| 机构审批人 | 按下述顺序添加评审人员。 |

【机构审批人】依次添加：**业务部门经理 → 运营经理 → 机构财务 → 机构总经理 → 发票云责任单位财务（孙轶南） → 责任单位总经理（陈少斌）**。

## 第二步：说明原因并上传附件

在【申请原因】中写明：

1. 申请分公司、签约客户、合同签订日期、合同编号、合同金额和已收款金额。
2. 退货原因，包括未满足的客户需求、引发因素、可能导致的结果及视情况需要说明的发生时间。
3. 处理经过，包括事件责任人、处理时间、处理人员、处理过程及结果，以及是否登门拜访挽留。
4. 涉及的产品及模块等详细信息。

在【退货处理报告&终止协议】处上传相关文件；【原合同或相关协议】可按实际情况上传。核对表单与附件后提交审批。

## 第三步：审批通过后重新订货

查看申请审批结果。流程通过后，换货重新订货时提交 **0元合同**，并附上退货不退款流程的单据编号。
