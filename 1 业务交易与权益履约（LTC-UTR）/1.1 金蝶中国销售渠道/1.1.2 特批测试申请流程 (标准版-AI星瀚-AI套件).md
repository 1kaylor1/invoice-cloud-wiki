# 特批测试申请流程（标准版 / AI星瀚 / AI套件）

## 适用范围与填写准备

适用于金蝶中国销售渠道为客户申请发票云测试或试用。请直接进入对应产品章节，按该产品的步骤顺序办理。

- **标准版**：开票、收票、影像，直接发起云之家申请。
- **AI星瀚**：开票、收票、电子影像，先申请 KBC 私有云临时许可；电子影像的云之家环节另有版本例外。
- **AI套件**：开票、收票，先申请 KBC 私有云临时许可，再办理云之家申请。

本文截至申请、审批及结果通知接收，交付、许可激活与下载、许可分配、产品登录和电子税局配置由独立文档说明。

### 云之家申请的共用字段

办理前准备下列信息，并确认具备对应云之家流程的发起权限。申请页面中带星号（*）的字段为必填项。产品选项、部署方式及期限按所办理产品章节填写。

| 字段        | 填写要求                                 |
| --------- | ------------------------------------ |
| 申请原因      | 说明客户测试需求，不超过200字                     |
| 企业全称      | 填合同签约客户的企业全称；签约主体与实际使用企业不一致时，按签约主体填写 |
| 企业税号      | 填上述签约主体对应的税号                         |
| 产品名称、部署方式 | 按对应产品章节选择系统中的产品名称和部署方式               |
| 用户数       | 填实际使用产品的税号或税盘数量，不是操作人员人数             |
| 开始时间、到期时间 | 按对应产品的期限和日期要求填写                      |
| 时长（天）     | 核对与所填日期是否一致                          |
| 联系电话      | 填可联系到的电话号码                           |
| 邮箱地址      | 填准确且能正常收信的邮箱，用于接收申请结果通知              |

**集团客户如何填写企业信息和用户数（开票、收票申请）**

签约主体与实际使用企业可能不同，企业信息和用户数需要分别填写。例如：由母公司 A 签约，两家子公司 A1、A2 各使用一个税号测试，则填写：

- **企业全称**：母公司 A 的企业全称。
- **企业税号**：母公司 A 的税号。
- **用户数**：2，代表本次实际使用产品的两个税号。

## 一、标准版测试申请

标准版开票、收票和影像均通过云之家“金蝶发票云测试授权申请”办理，无需申请 KBC 临时许可。三类产品共用以下申请步骤，选品、部署方式和期限按产品分别填写。

### 标准版产品选择与申请要求

| 申请产品 | 产品名称选项 | 支持申请的部署方式 | 期限与特殊要求 |
|---|---|---|---|
| 标准版开票测试 | 开票管理（标准版）_6.0 | 仅适用于公有云部署的标准版开票测试，部署方式选择“公有云（订阅）” | 标准版开票的数电票测试通道最多使用 **30天** |
| 标准版收票测试 | 基础收票管理（标准版）_6.0 | 仅适用于公有云部署的标准版收票测试，部署方式选择“公有云（订阅）” | 标准版收票测试**无需选择“发票校验流量包（标准版）”**；云之家测试授权单次申请时长不超过 **90天** |
| 标准版影像测试 | 电子影像服务，版本5.0 | **公有云和私有云均支持申请**，按客户实际部署方式选择 | 标准版影像试用有效期 **60天，不可延长**；开始时间不得晚于申请当日 |

### 第一步：进入标准版测试授权申请

进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请**。

### 第二步：选择标准版产品和部署方式

1. 打开【产品名称】下拉框，可输入名称搜索，按上表选择开票、收票或影像产品。
2. 标准版开票、收票选择 **公有云（订阅）**；标准版影像按客户实际部署方式选择 **公有云或私有云**。
3. 申请标准版收票时，选择 **基础收票管理（标准版）_6.0**，无需另选发票校验流量包。

### 第三步：填写标准版测试申请信息

1. **企业全称、企业税号**：填写合同签约客户的企业全称及税号；签约主体与实际使用企业不同的，仍按签约主体填写。
2. **用户数**：填写实际使用产品的税号或税盘数量，不是操作人员人数。
3. **开始时间、到期时间**：填写所需测试日期，并核对【时长（天）】：
   - 标准版开票申请的数电票测试通道最多使用 **30天**。
   - 标准版收票按所需日期申请，云之家测试授权单次申请时长不超过 **90天**。
   - 标准版影像按 **60天**试用有效期填写，开始时间选择申请当日或以前的日期，不可申请延期。
4. **联系电话、邮箱地址**：填写可联系到的电话和能正常收信的邮箱，申请结果发往该邮箱。
5. **申请原因**：说明客户测试需求，不超过200字。
6. 核对页面中带星号的必填项；需要补充材料时，通过【附件】上传。可点击【存为草稿】暂存，信息确认完整后再提交。

### 第四步：提交标准版测试申请

核对产品名称、部署方式、签约主体、用户数、日期和邮箱，点击【提交】发起审批，随后在该申请中查看审批结果。

### 第五步：接收标准版测试申请结果

审批通过后，系统将测试使用信息发送至申请表中填写的邮箱。

标准版开票、收票审批通过半小时仍未收到邮件，或标准版影像未收到测试登录信息时，统一联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。

收到结果通知后，按独立的产品交付与激活指引办理后续操作。

## 二、AI星瀚测试申请

本节适用于申请私有云部署的 AI星瀚开票、收票和电子影像测试。三类产品均先申请 KBC 临时许可，再按下述条件办理云之家测试授权；产品选项和个别处理方式不同。

### AI星瀚产品选择

KBC 产品统一选择 **金蝶发票云（旗舰版）私有云（订阅）**，版本选择 **6.0**，模块及云之家产品选项按下表填写。

| 申请产品 | KBC 模块 | 云之家产品名称 |
|---|---|---|
| AI星瀚开票测试 | 开票管理 | 开票管理（For AI 星瀚）_6.0 |
| AI星瀚收票测试 | 收票管理 | 收票管理（For AI 星瀚）_6.0 |
| AI星瀚电子影像测试 | 电子影像 | 电子影像（旗舰版）私有云（订阅） |

### AI星瀚测试申请条件与期限

- **KBC 临时许可期限**：AI星瀚开票、收票和电子影像的 KBC 订阅产品临时许可，单次申请最长 **90天**，且不得超过租赁剩余时长。
- **开票测试方式**：AI星瀚开票可使用星瀚自带虚拟 UKEY 测试；申请数电票测试通道时，通道最多使用 **30天**。
- **申请权限**：产品已迁移至 KBC 时，申请人须为 KBC【客户权益】中有该产品经营权的客户经理或客户成功经理；尚未迁移至 KBC 时，须具备 icrm 客户档案中对应角色的申请权限。
- **合同与模块**：KBC 新购合同签订后可申请“老客户测试”类临时许可，合同未交付也可申请；该场景模块由系统带出，不允许自行调整。
- **已购公有云产品的客户**：在【申请销售产品】中选择对应私有云订阅版本，申请到的临时许可不包含公有云模块。

### 第一步：申请AI星瀚 KBC 临时许可

1. 直销进入 **KBC → 销售管理 → 产品交付 → 临时许可申请**；分销进入 **KBC → 业务中心 → 产品交付 → 临时许可申请**。
2. 点击【新增】，使用对象类型选择 **客户**。
3. 产品选择 **金蝶发票云（旗舰版）私有云（订阅）**，版本选择 **6.0**，模块按所申请的开票、收票或电子影像产品选择。
4. 选择客户和申请场景，填写申请期限，单次最长 **90天**且不得超过租赁剩余时长。核对必填信息后提交申请并办理审批。
5. 找不到产品或对 KBC 临时许可申请有疑问时，联系 **尤福欢**。

### 第二步：申请AI星瀚云之家测试授权

**电子影像版本例外**：AI星瀚电子影像客户使用星瀚7.0以上版本时，无需发起云之家测试授权申请；完成 KBC 临时许可申请后，转入交付环节。版本正好为7.0时，先确认是否符合免申请条件。开票、收票和需要云之家申请的电子影像客户，继续以下操作。

1. 进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请**。
2. 按“AI星瀚产品选择”表选择产品名称，部署方式选择 **私有云（订阅）**。
3. 填写申请原因、合同签约企业全称及税号、实际使用的税号或税盘数量（用户数）、申请起止日期、联系电话和收信邮箱。
4. AI星瀚开票需要数电票测试通道时，按最多 **30天**安排通道测试日期。
5. 核对必填信息，点击【提交】发起审批，并在该申请中查看审批结果。

### 第三步：接收AI星瀚测试申请结果

- **开票、收票**：审批通过后，系统将测试使用信息发送至申请表填写的邮箱。
- **电子影像**：需要云之家申请的客户，审批通过后联系 **杨慧莉** 对接许可文件。

开票、收票审批通过半小时仍未收到邮件，或办理过程中遇到其他问题时，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。后续交付与激活操作由独立文档说明。

## 三、AI套件测试申请

本节适用于申请私有云（订阅）部署的 AI套件开票和收票测试。两类产品均先申请 KBC 临时许可，再申请云之家测试授权，按同一套流程办理。

### AI套件产品选择

KBC 产品统一选择 **金蝶发票云【星空旗舰版】私有云（订阅）**，版本选择 **1.0**，模块及云之家产品选项按下表填写。

| 申请产品 | KBC 模块 | 云之家产品名称 |
|---|---|---|
| AI套件开票测试 | 开票管理（星空旗舰版） | 开票管理（星空旗舰版） |
| AI套件收票测试 | 基础收票管理（星空旗舰版） | 基础收票管理（星空旗舰版） |

### AI套件测试申请条件与期限

- **KBC 临时许可期限**：AI套件开票和收票的 KBC 订阅产品临时许可，单次申请最长 **90天**，且不得超过租赁剩余时长。
- **开票测试通道期限**：AI套件开票申请的数电票测试通道最多使用 **30天**。
- **申请权限**：产品已迁移至 KBC 时，申请人须为 KBC【客户权益】中有该产品经营权的客户经理或客户成功经理；尚未迁移至 KBC 时，须具备 icrm 客户档案中对应角色的申请权限。
- **合同与模块**：KBC 新购合同签订后可申请“老客户测试”类临时许可，合同未交付也可申请；该场景模块由系统带出，不允许自行调整。
- **已购公有云产品的客户**：在【申请销售产品】中选择对应私有云订阅版本，申请到的临时许可不包含公有云模块。

### 第一步：申请AI套件 KBC 临时许可

1. 直销进入 **KBC → 销售管理 → 产品交付 → 临时许可申请**；分销进入 **KBC → 业务中心 → 产品交付 → 临时许可申请**。
2. 点击【新增】，使用对象类型选择 **客户**。
3. 产品选择 **金蝶发票云【星空旗舰版】私有云（订阅）**，版本选择 **1.0**，模块按所申请的开票或收票产品选择。
4. 选择客户和申请场景，填写申请期限，单次最长 **90天**且不得超过租赁剩余时长。核对必填信息后提交申请并办理审批。
5. 找不到产品或对 KBC 临时许可申请有疑问时，联系 **尤福欢**。

### 第二步：申请AI套件云之家测试授权

1. 进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请**。
2. 按“AI套件产品选择”表选择产品名称，部署方式选择 **私有云（订阅）**。
3. 填写申请原因、合同签约企业全称及税号、实际使用的税号或税盘数量（用户数）、申请起止日期、联系电话和收信邮箱。
4. AI套件开票需要数电票测试通道时，按最多 **30天**安排通道测试日期。
5. 核对必填信息，点击【提交】发起审批，并在该申请中查看审批结果。

### 第三步：接收AI套件测试申请结果

审批通过后，系统将 AI套件测试使用信息发送至申请表填写的邮箱。半小时内仍未收到邮件，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。

后续交付与激活操作由独立文档说明。
