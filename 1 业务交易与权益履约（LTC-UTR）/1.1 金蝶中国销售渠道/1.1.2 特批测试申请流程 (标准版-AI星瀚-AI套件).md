# 特批测试申请流程（标准版 / AI星瀚 / AI套件）

## 适用场景与前置准备

金蝶中国销售渠道为客户申请发票云产品测试或试用时，按本文选择对应申请分支。本文覆盖标准版开票、收票、影像，AI星瀚开票、收票、电子影像，以及 AI套件开票、收票。

本文只说明申请、审批和申请结果接收。产品交付、临时许可激活与下载、许可分配、产品登录及电子税局配置由独立文档说明。

原始申请界面使用旧产品名称：**AI星瀚对应“旗舰版”，AI套件对应“星空旗舰版”**。提单时按下表保留界面名称，不直接把下拉选项改写成新名称。

办理前准备：

- 申请原因、合同签约客户的企业全称及企业税号。
- 实际使用产品的税号或税盘数量、拟申请的开始和到期日期。
- 联系电话及能正常收信的邮箱地址。
- 云之家对应流程的发起权限；需申请 KBC 临时许可时，还需具备下文所列的 KBC 申请权限。

这里的私有云限制来自上述测试申请指引，仅用于本文流程，不代表产品全部部署能力。

### 期限与填写要求

- **30天是数电票测试通道的上限**，不能直接用作所有产品测试许可的统一有效期。
- **标准版影像有效期60天，不可延长**。该分支的开始时间须选择申请当日或以前的日期，不能选未来日期；此要求来自影像标准版原文，不推广到其他产品。
- **KBC 订阅产品临时许可**：申请时长不得超过租赁剩余时长，且单次最长90天。该规则来自五份私有云指引中的“客户用临时许可—申请”截图，不代表云之家各产品的统一期限。
- 原文未给出标准版收票等产品独立的统一试用天数，不自行套用上述30天、60天或90天。界面截图中的历史日期及“139天”是示例，不是申请期限规则。
- 企业全称和企业税号填写**合同签约客户主体**的信息。对于开票、收票指引中的集团示例：母公司 A 申请两个授权给子公司 A1、A2 使用，企业信息填母公司 A，用户数填2。

## 操作步骤

### 第一步：确定产品分支与是否需要 KBC 申请

1. 根据“各产品申请路径”表确定产品、版本和部署方式。
2. 标准版按第三步直接进入云之家申请。
3. AI星瀚、AI套件私有云产品先办理第二步的 KBC 临时许可申请，再按产品分支办理云之家流程。
4. AI星瀚电子影像如符合原文“客户星瀚7.0以上版本”的条件，不继续办理下述云之家测试授权流程；该例外只针对云之家环节，不据此省略 KBC 临时许可申请。

### 第二步：申请 KBC 临时许可（AI星瀚、AI套件）

**入口**：

- 直销：**KBC → 销售管理 → 产品交付 → 临时许可申请**。
- 分销：**KBC → 业务中心 → 产品交付 → 临时许可申请**。

原文正文也将末级入口写作“申请临时许可”，按实际页面名称进入对应功能。

**申请权限**：

- 产品已迁移至 KBC：客户在 KBC【客户权益】中，有产品经营权的“客户经理/客户成功经理”具有申请权限。
- 产品尚未迁移至 KBC：按原图说明，使用 icrm 客户档案中的“客户经理/客户成功经理”申请权限。
- 找不到产品或对申请有疑问时，原文指定咨询尤福欢；需确认联系人是否仍负责时，先核实再提交。

**填写与提交**：

1. 在临时许可申请列表点击【新增】，使用对象类型选择“客户”。
2. 按下表选择申请产品、版本和模块，其他信息按页面要求据实填写。

| 本文产品 | KBC 产品 | 版本号 | 模块 |
|---|---|---|---|
| AI星瀚开票 | 金蝶发票云（旗舰版）私有云（订阅） | 6.0 | 开票管理 |
| AI星瀚收票 | 金蝶发票云（旗舰版）私有云（订阅） | 6.0 | 收票管理 |
| AI星瀚电子影像 | 金蝶发票云（旗舰版）私有云（订阅） | 6.0 | 电子影像 |
| AI套件开票 | 金蝶发票云【星空旗舰版】私有云（订阅） | 1.0 | 开票管理（星空旗舰版） |
| AI套件收票 | 金蝶发票云【星空旗舰版】私有云（订阅） | 1.0 | 基础收票管理（星空旗舰版） |

3. 按客户实际场景选择产品及期限。原图说明：KBC 新购合同签订后，即可申请“老客户测试”类临时许可，合同未交付也可申请；此场景的模块由系统带出，不允许自行调整。
4. 如客户已购产品为公有云，原图要求在【申请销售产品】处选择对应的私有云订阅版本，申请到的临时许可不包含公有云模块。该说明不代表本流程可以申请公有云测试许可。
5. 核对期限和产品信息，提交申请并办理审批。原文未列出全部 KBC 表单字段和审批责任人，按实际页面要求处理，不另行指定审批人。

此处完成 KBC 申请环节即可；后续激活及许可文件操作不在本文展开。

### 第三步：进入云之家测试授权申请

1. 进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请审批流程**。
2. 影像标准版原文将入口写作“云之家 → 智能申请 → 金蝶发票云测试授权申请”，按实际可见的对应流程进入。
3. 再次核对产品分支。AI星瀚电子影像符合前述版本例外时，跳过此环节；其他分支按下表填写。

### 第四步：填写云之家申请表

以下内容由原文及申请表截图整理；页面带星号的项目需填写，截图未展示的字段以实际页面为准。

| 字段 | 是否必填 | 填写要求 |
|---|---|---|
| 申请原因 | 是 | 说明客户申请测试的原因；截图显示最多200字 |
| 企业全称 | 是 | 填合同签约客户的企业全称；截图提示“租户名称（非使用企业）”，不要把集团下实际使用企业误填为签约主体 |
| 企业税号 | 是 | 与上述合同签约主体对应 |
| 产品名称 | 是 | 按“各产品申请路径”表选择，注意标准版、旗舰版和星空旗舰版的区别 |
| 部署方式 | 页面显示时按要求填写 | 标准版开票、收票选公有云；私有云产品按原文指定方式选择。影像标准版截图显示该字段为必填，但原文未给选项，见文末待确认项 |
| 用户数 | 是 | 截图注明代表使用产品的税号或税盘数量，不是操作人员人数；开票、收票集团场景可参考前述示例 |
| 开始时间、到期时间 | 是 | 按本产品适用期限填写；影像标准版开始时间不能晚于申请当日 |
| 时长（天） | 未见必填标记 | 核对其与申请日期及产品期限是否一致，不照抄截图中的示例数值 |
| 联系电话 | 是 | 填可联系到的电话号码 |
| 邮箱地址 | 是 | 填写准确、能接收通知的邮箱；开票、收票审批通过后的邮件发往这里 |

填写产品时特别注意：

- 标准版收票选择“基础收票管理（标准版）”，无需选择“发票校验流量包（标准版）”。
- 标准版影像按原文选择“电子影像服务”，版本5.0。
- AI星瀚电子影像需要云之家申请时，按原文选择“电子影像（旗舰版）私有云（订阅）”，部署方式选“私有云（订阅）”。
- 其他产品按表中原始选项填写，不将不同版本的开票或收票选项混用。

### 第五步：提交申请并查看结果

1. 核对签约主体、税号、产品、用户数、日期和邮箱地址，确认页面必填项完整后点击【提交】，进入审批。
2. 在对应申请流程中查看审批结果。提交申请不等于审批通过，也不等于产品已激活。
3. 标准版开票、收票及 AI星瀚、AI套件开票、收票：原文说明审批通过后会发送邮件，开票私有云指引另注明自动生成授权；在预留邮箱确认是否收到结果通知。
4. 标准版影像：原文说明测试登录信息通过邮件发送；本文仅保留结果接收方式，不展开登录使用。
5. AI星瀚电子影像：需要云之家申请的分支，原文说明审批通过后联系杨慧莉获取许可文件。此处仅说明后续对接，许可获取、交付与激活操作由独立文档说明。

## 申请异常与待确认事项

### 申请中遇到问题

- **KBC 找不到产品或申请权限有疑问**：先核对客户经营权、申请角色、产品及模块选择；原文指定尤福欢作为咨询联系人，当前职责需核实。
- **审批通过半小时仍未收到邮件**：标准版开票及 AI星瀚、AI套件开票和收票原文指向[发票云在线客服](https://tax.piaozone.com/sobot-web/home)；标准版收票原文指定联系云之家“龚敏君”。不要将半小时等待口径直接套用到原文未说明的影像分支。
- **AI星瀚电子影像审批通过后的许可对接**：原文指定杨慧莉；当前职责需核实，本文不替代独立的交付指引。

### 使用相关分支前需确认

- **标准版影像部署选项**：原文要求填写部署方式，但未给出应选值。`【待确认：电子影像服务5.0测试申请应选择的部署方式】`。
- **AI星瀚电子影像版本例外**：原文表述为“客户星瀚是7.0以上版本，不用走以下流程”。`【待确认：“7.0以上”是否包含7.0本身，以及当前客户版本是否符合免走云之家流程的条件】`。不得据此取消其他产品的申请环节。
- **AI套件开票虚拟 UKEY**：原始星空旗舰版指引写有“也可以使用星瀚自带虚拟UKEY测试”，产品名称与上下文不一致。`【待确认：AI套件开票实际支持的虚拟UKEY测试方式】`；确认前不将该表述作为 AI套件可直接执行的说明。
