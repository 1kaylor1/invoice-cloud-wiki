# 特批测试申请流程（标准版 / AI星瀚 / AI套件）

## 适用范围与填写准备

适用于金蝶中国销售渠道为客户申请发票云测试或试用。请直接进入对应产品章节，按该产品的步骤顺序办理。

- **标准版**：开票、收票、影像，直接发起云之家申请。
- **AI星瀚（原旗舰版）**：开票、收票、电子影像，先申请 KBC 私有云临时许可；电子影像的云之家环节另有版本例外。
- **AI套件（原星空旗舰版）**：开票、收票，先申请 KBC 私有云临时许可，再办理云之家申请。

本文截至申请、审批及结果通知接收，交付、许可激活与下载、许可分配、产品登录和电子税局配置由独立文档说明。

### 云之家申请的共用字段

办理前准备下列信息，并确认具备对应云之家流程的发起权限。产品选项、部署方式及期限按所办理产品章节填写。

| 字段 | 填写要求 |
|---|---|
| 申请原因 | 说明客户测试需求；申请截图显示最多200字 |
| 企业全称 | 填合同签约客户的企业全称；界面提示为租户名称，不是实际使用企业名称 |
| 企业税号 | 填上述签约主体对应的税号 |
| 产品名称、部署方式 | 按对应产品章节填写，保留系统中的“旗舰版”“星空旗舰版”等名称 |
| 用户数 | 填实际使用产品的税号或税盘数量，不是操作人员人数 |
| 开始时间、到期时间 | 按对应产品的期限和日期要求填写 |
| 时长（天） | 核对与所填日期是否一致 |
| 联系电话 | 填可联系到的电话号码 |
| 邮箱地址 | 填准确且能正常收信的邮箱，用于接收申请结果通知 |

页面带星号的项目均须填写。开票、收票的集团客户填写示例：母公司 A 签约，申请两个授权给子公司 A1、A2 使用，企业信息填母公司 A，用户数填2。

## 一、标准版测试申请

### 1. 开票标准版

[原始申请指引](https://icn1dae2f6c3.feishu.cn/wiki/QaMtwyyqCix5rFkKyYTcxLA9npx)

**申请要求**：公有云；数电票测试通道最多使用 **30天**。

#### 第一步：进入云之家申请

进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请审批流程**。

#### 第二步：填写并提交

1. 按共用字段说明填写申请原因、签约企业全称和税号、用户数、日期及联系方式。
2. 产品选择 **开票管理（标准版）**，部署方式选择 **公有云**。申请数电票测试通道时，按最多30天安排测试日期。
3. 核对必填信息，点击【提交】发起审批。

#### 第三步：接收申请结果

审批通过后系统自动发送邮件至预留邮箱。半小时内未收到邮件，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。

### 2. 收票标准版

[原始申请指引](https://icn1dae2f6c3.feishu.cn/wiki/HA3lwFuy1iYhNKkPnXLcscb7nJc)

**申请要求**：公有云；**无需选择“发票校验流量包（标准版）”**。

#### 第一步：进入云之家申请

进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请审批流程**。

#### 第二步：填写并提交

1. 按共用字段说明填写申请原因、签约企业全称和税号、用户数、日期及联系方式。
2. 产品选择 **基础收票管理（标准版）**，部署方式选择 **公有云**。不勾选“发票校验流量包（标准版）”。
3. 核对必填信息，点击【提交】发起审批。

#### 第三步：接收申请结果

审批通过后系统自动发送邮件至预留邮箱。半小时内未收到邮件，联系云之家 **龚敏君**。

### 3. 影像标准版

[原始申请指引](https://icn1dae2f6c3.feishu.cn/wiki/E7tQwoBchiTEVik7xUicjhy7nmb)

**申请要求**：试用有效期 **60天，不可延长**；开始时间必须选择申请当日或以前的日期，不能选择未来日期。

#### 第一步：进入云之家申请

进入 **云之家 → 智能申请 → 金蝶发票云测试授权申请**。

#### 第二步：填写并提交

1. 按共用字段说明填写申请原因、签约企业全称和税号、用户数、日期及联系方式。
2. 产品选择 **电子影像服务**，版本选择 **5.0**。开始时间不晚于申请当日，按60天试用有效期填写日期。
3. 申请截图中部署方式为必填，但原文未给选项。**【待确认：电子影像服务5.0测试申请的部署方式选项】**，确认后填写并提交。
4. 必填信息确认完整后，点击【提交】发起审批。

#### 第三步：接收申请结果

测试登录信息通过邮件发送，确认预留邮箱收到通知。本文不展开产品登录和使用操作。


## 二、AI星瀚测试申请（原旗舰版）

### KBC 申请前提与期限

以下要求适用于本节各产品的私有云测试申请：

- **期限**：订阅产品临时许可申请时长不得超过租赁剩余时长，且单次最长 **90天**。
- **申请权限**：已迁移至 KBC 的产品，由 KBC【客户权益】中有该产品经营权的“客户经理/客户成功经理”申请；尚未迁移至 KBC 的产品，按原指引由 icrm 客户档案中的“客户经理/客户成功经理”申请。
- **合同与模块**：KBC 新购合同签订后可申请“老客户测试”类临时许可，合同未交付也可申请；该场景模块由系统带出，不允许自行调整。
- **已购公有云产品的客户**：在【申请销售产品】中选择对应私有云订阅版本，申请到的临时许可不包含公有云模块。
- **申请入口**：直销使用 **KBC → 销售管理 → 产品交付 → 临时许可申请**；分销使用 **KBC → 业务中心 → 产品交付 → 临时许可申请**。末级菜单也可能显示为“申请临时许可”。
- **申请咨询**：找不到产品或对申请有疑问时，联系 **尤福欢**。

### 1. AI星瀚开票

[原始申请指引](https://icn1dae2f6c3.feishu.cn/wiki/X6yZwusVci7pA7kBGspcRt5Mn6d)

**申请要求**：私有云；可使用星瀚自带虚拟 UKEY 测试，使用数电票测试通道时最多 **30天**。KBC 临时许可期限按本节前述要求办理。

#### 第一步：申请 KBC 临时许可

1. 从本节列出的直销或分销入口进入临时许可申请列表，点击【新增】，使用对象类型选择 **客户**。
2. 产品选择 **金蝶发票云（旗舰版）私有云（订阅）**，版本 **6.0**，模块 **开票管理**。
3. 按本节 KBC 要求选择客户、申请场景及期限，补齐页面要求的信息，提交申请并办理审批。

#### 第二步：申请云之家测试授权

1. 进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请审批流程**。
2. 按共用字段说明填写签约客户、申请原因、用户数、日期和联系方式。
3. 产品选择 **开票管理（旗舰版）**，按私有云部署方式填写。需要数电票测试通道时，按30天上限安排测试。
4. 核对必填信息并点击【提交】，查看审批结果。

#### 第三步：接收申请结果

审批通过后系统自动生成授权并发送邮件。半小时内未收到邮件，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。

### 3. AI星瀚电子影像

[原始申请指引](https://icn1dae2f6c3.feishu.cn/wiki/PBG7w81gfixPhfkhtkucoloWnbb)

**申请要求**：私有云（订阅）；KBC 临时许可期限按本节前述要求办理。客户星瀚版本决定是否需要云之家环节。

#### 第一步：申请 KBC 临时许可

1. 从本节列出的直销或分销入口进入临时许可申请列表，点击【新增】，使用对象类型选择 **客户**。
2. 产品选择 **金蝶发票云（旗舰版）私有云（订阅）**，版本 **6.0**，模块 **电子影像**。
3. 按本节 KBC 要求选择客户、申请场景及期限，补齐页面要求的信息，提交申请并办理审批。

#### 第二步：按星瀚版本判断云之家申请

- 客户符合原指引“星瀚7.0以上版本”条件时，无需走云之家测试授权申请，到此结束本文申请环节；KBC 仍按第一步办理。
- 需要云之家申请的客户，继续第三步。
- **【待确认：原指引“7.0以上”是否包含7.0本身】**。客户版本正好为7.0时，先确认后再决定是否免走云之家流程。

#### 第三步：申请云之家测试授权（需要申请的客户）

1. 进入 **云之家 → 智能审批 → 金蝶发票云测试授权申请审批流程**。
2. 按共用字段说明填写签约客户、申请原因、用户数、日期和联系方式。
3. 产品选择 **电子影像（旗舰版）私有云（订阅）**，部署方式选择 **私有云（订阅）**。
4. 核对必填信息并点击【提交】，查看审批结果。

#### 第四步：接收申请结果

需要云之家申请的客户，审批通过后联系 **杨慧莉** 对接许可文件；交付与激活操作由独立文档说明。
