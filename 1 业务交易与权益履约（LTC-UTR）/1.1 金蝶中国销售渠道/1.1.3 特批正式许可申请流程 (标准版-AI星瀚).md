# 特批正式许可申请流程（标准版 / AI星瀚）

本文适用于金蝶中国销售渠道为客户提前开通标准版或 AI星瀚开票、收票、电子影像的正式许可，说明申请、审批和结果接收。后续许可分配、激活与交付另行办理；测试申请请参见[特批测试申请流程](<1.1.2 特批测试申请流程 (标准版-AI星瀚-AI套件).md>)。

## 一、标准版提前开通申请

标准版开票、收票和影像通过云之家智能审批申请。开票、收票适用公有云；影像按实际申请公有云或私有云。

### 申请条件

- 标准版提前开通的特批时间不得超过 **30天**，须有签署中的合同文件支持。
- 书面承诺正式合同产品启用时间不晚于本次特批启用时间，且合同购买数量大于特批启用数量；否则额外产生的成本由对应机构承担。

### 第一步：填写并提交云之家申请

1. 进入 **云之家 → 智能审批 → 金蝶发票云产品特批订单申请审批流程**。
2. 在【申请原因】中写明与客户签订协议约定的开始、结束日期和预计 KBC 交付出库日期，并承诺未按期订货造成的损失由机构承担。附件上传与客户签约的合同文件。
3. 填写合同签约客户的企业全称及税号，按页面要求填写申请起止时间、联系电话、邮箱等信息；带星号的字段为必填项。开票、收票申请中的用户数按使用产品的税号或税盘数量填写。
4. 按下表选择产品和部署方式，核对信息后提交审批。

| 申请产品 | 产品选项 | 部署方式及注意事项 |
|---|---|---|
| 标准版开票 | 开票管理（标准版） | 公有云 |
| 标准版收票 | 基础收票管理（标准版） | 公有云；无需选择发票校验流量包（标准版） |
| 标准版影像 | 电子影像服务，5.0 | 按实际选择公有云或私有云 |

例如，母公司 A 签约，为子公司 A1、A2 各申请一个开票或收票授权时，企业全称和税号填写母公司信息，用户数填写 2。

### 第二步：接收审批结果

- **开票、收票**：审批通过后，系统向申请表填写的邮箱自动发送激活邮件。半小时内未收到时，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。
- **影像公有云**：申请表填写的邮箱接收登录地址，密码为手机号后六位。
- **影像私有云**：申请表填写的邮箱接收私有化许可。

## 二、AI星瀚提前开通申请

本节适用于 AI星瀚开票、收票、电子影像的私有云申请。原申请界面使用“旗舰版”名称。先办理 KBC 特批正式许可，再按产品及版本办理云之家审批。

### 申请准备

- 准备《提前使用金蝶正式许可申请函》和《提前向客户提供正式许可保证书》，模板可在 KBC 申请页面下载。
- 后续正式合同按提前使用正式许可的开始时间计算租赁期费用。
- KBC 申请权限为 RBU 销售人员全体、总部各环境管理人员。

### 第一步：申请 KBC 特批正式许可

1. 进入 **KBC → 销售管理 → 产品交付 → 特批正式许可申请**。
2. 在申请列表中新增申请单，填写相关信息，上传申请函、保证书等附件，并按客户需求选择对应模块及用户。电子影像选择 **金蝶发票云（旗舰版）私有云（订阅）**的电子影像模块。
3. 提交申请；可点击【查看流程图】查看审批进展。审核通过后，在申请单详情页查看结果。客户许可的激活码以 **SP** 开头，不是申请编号。

### 第二步：按产品和版本申请云之家审批

**电子影像例外**：客户使用的星瀚版本高于 7.0 时，无需办理本步骤的云之家审批；版本恰为 7.0 时，先确认适用要求。开票、收票及需要办理云之家审批的电子影像继续以下步骤。

1. 进入 **云之家 → 智能审批 → 金蝶发票云产品特批订单申请**。
2. 在【申请原因】中写明与客户签订协议约定的开始、结束日期、预计 KBC 交付出库日期，并承诺未按期订货造成的损失由机构承担；附件上传与客户签约的合同文件。
3. 企业全称及企业税号填写合同签约客户的信息；开票、收票的用户数按实际使用产品的税号或税盘数量填写。填写申请时间、联系方式、邮箱等页面要求的信息，带星号的字段为必填项。
4. 依据下表选择产品，部署方式选择 **私有云（订阅）**，核对后提交审批。

| 申请产品 | 云之家产品选项 |
|---|---|
| AI星瀚开票 | 开票管理（旗舰版） |
| AI星瀚收票 | 基础收票管理（旗舰版） |
| AI星瀚电子影像 | 电子影像（旗舰版）私有云（订阅），6.0 |

### 第三步：接收审批结果

- **开票、收票**：云之家审批通过后，系统向申请表填写的邮箱自动发送激活邮件。半小时内未收到时，联系[发票云在线客服](https://tax.piaozone.com/sobot-web/home)。
- **需要云之家审批的电子影像**：智能审批通过后，联系 **杨慧莉**获取许可文件。
- **星瀚版本高于 7.0 的电子影像**：完成 KBC 特批正式许可申请后，按许可使用对象办理后续激活和交付。
