# 第三方采购合同审核与付款流转

## 1. 适用场景

适用于发票云交付或运维过程中，需向航天信息、百旺金赋、硬件厂商或外部服务商采购物理设备、税控加密狗、通道接口时的采购合同审核与付款申请。

## 2. 申请前置要求

* 已完成 [第三方通道与硬件采购询价流程](../1.1%20商机、测试与售前支撑/1.1.2%20第三方通道与硬件采购询价流程.md) 并取得有效报价单。
* 供应商资质符合金蝶采购准入规范（含三证合一执照、开户许可证）。
* 终端客户对应的销售合同已签署或回款已到达可采购节点。

## 3. 操作步骤

### 第一步：起草采购合同与会签
1. 采用金蝶标准采购合同模板，录入供应商信息、采购硬件型号、数量、单价及交货维保条款。
2. 附上终端客户关联订单编号及询价确认单。
3. 提交合同审批系统，经发票云运营接口人、法务、商务会签。

### 第二步：发起付款提单
1. 收到供应商提供的合规增值税专用发票并完成查验。
2. 在财务报销系统/ERP 中发起“对公预付款”或“应付账款结算”提单。
3. 审批流经运营负责人 $\rightarrow$ 财务审核 $\rightarrow$ 资金出纳打款。

## 4. 注意事项
* 凡涉及预付款项，必须严格核对交货期与验收入库单。
* 采购发票原件需及时移交财务档案室归档。
