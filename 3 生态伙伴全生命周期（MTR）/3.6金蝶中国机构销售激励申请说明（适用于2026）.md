# 金蝶中国机构销售激励申请说明（适用于2026）

本文面向金蝶中国机构的销售与运营经办人，说明销售激励申请的入口、填报及提交操作，办理终点为申请提交并进入审核流程；激励资格、金额计算及发放按对应激励方案办理。

## 申请入口与迁移规则

**自2026年11月1日起，新发起的销售激励类申请统一通过KBC办理，智能审批入口关闭，不再受理新申请。**

| 申请情形 | 办理方式 |
|---|---|
| 2026年11月1日起新发起的销售激励申请 | 通过 **KBC → 销售管理 → 销售权益 → 销售激励申请** 提交 |
| 2026年11月1日前已通过智能审批发起、尚在流转中的销售激励申请 | 继续按原流程审批，不受迁移影响，无需重新提交 |

在KBC销售管理页面展开“销售权益”后，可在“销售激励”分组下找到“销售激励申请”。

## 申请前准备

- 确认本次申请对应的激励方案及适用条件。发票云订阅产品专项激励对应的系统方案名称为“2026年发票云订阅产品专项激励”。
- 准备申请对应的销售合同、参与激励的产品明细、申请金额及业绩说明。
- 根据所选方案准备所需激励信息及证明材料；对适用条件或激励口径有疑问时，先向激励活动负责人确认。

不同激励方案的填报字段可能不同，按所选方案的系统提示填写。其他方案中展示的产品、金额和字段不作为发票云方案的统一申请条件。

## 操作步骤

### 第一步：进入销售激励申请页面

登录KBC，进入 **销售管理 → 销售权益 → 销售激励申请**，打开申请页面。

核对系统自动带出的单据编号、销售组织、销售部门、销售人员、工号、职位等基本信息。新建申请的单据状态默认为“暂存”。

### 第二步：选择激励方案并填写基本申请信息

在“基本信息”区域选择本次申请对应的“销售激励方案”，并填写以下内容。

| 字段或区域 | 填报说明 |
|---|---|
| 销售激励方案 | 必填。按申请活动选择；申请发票云订阅产品专项激励时，选择“2026年发票云订阅产品专项激励” |
| 激励币别 | 必填。系统默认“人民币”，核对本次申请适用币别 |
| 激励总额 | 必填。填写本次申请的激励金额 |
| 业绩说明及相关背景 | 填写本次申请的业绩说明及相关背景 |
| 附件信息 | 如需补充证明材料，点击“上传文件”添加附件 |

### 第三步：选择对应销售合同

1. 在“合同信息”区域点击“合同编号”右侧的搜索按钮，打开“销售合同”选择窗口。
2. 选择本次申请对应的合同，点击“确定”。
3. 核对系统带出的客户名称、合同币别、产品名称、累计收款、签订日期等信息。

“合同编号”为必填项，所选合同应与本次激励申请对应。

### 第四步：勾选参与激励的产品

1. 在“勾选参与激励的产品信息”窗口中，按所选激励方案的规则勾选符合条件的产品行。
2. 核对所选产品的物料、版本、数量、用户数或人天数、开始日期、截至日期、标准报价、实际报价、累计收款、收款时间、销售折扣及实际成本等信息。
3. 点击“确定”，完成产品选择。

### 第五步：填写方案对应的激励信息

选择激励方案后，系统自动生成对应的“激励信息”字段，按本次方案要求填写。

部分方案包含“新签首年订阅金额”“首年订阅费是否全额”“回款日期”等字段；这些字段仅用于说明方案之间的填报差异，具体以当前所选方案的字段及提示为准。

### 第六步：核对并提交申请

提交前，核对激励方案、币别、激励总额、合同、参与激励的产品、激励信息、业绩说明及已上传附件。

| 操作按钮 | 用途 |
|---|---|
| 保存 | 暂存申请，后续可继续修改 |
| 提交 | 提交当前申请，进入审核流程 |
| 提交并新增 | 提交当前申请并继续新增申请 |

信息确认无误后，点击“提交”或“提交并新增”。需要继续补充内容时，可先点击“保存”。

## 提交结果与业务咨询

- 单据仍为“暂存”时，仅完成草稿保存，尚未完成申请提交。
- 申请提交后进入审核流程。本文的操作完成点为完成提交，审核及激励发放按对应方案后续办理。
- 对激励方案适用条件或金额口径有疑问，联系激励活动负责人确认；对流程迁移及执行有疑问，联系董亮咨询。
