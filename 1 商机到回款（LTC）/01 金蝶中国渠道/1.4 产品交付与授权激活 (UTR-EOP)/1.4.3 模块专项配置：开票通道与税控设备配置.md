# 模块专项配置：开票通道与税控设备配置

## 1. 适用场景

发票云租户激活完成后，开通开票模块时的参数连通性配置。涵盖全面数字化的电子发票（数电票）直连模式，以及传统税控盘/金税盘/税务服务器接入模式。

## 2. 前置条件

* 客户租户已创建并已绑定开票产品许可。
* 客户已向主管税务机关完成数电开票资质报备，或税控服务器已就位且IP网络连通。
* 运营人员具备 EOP 系统通道配置权限与运营运维权限。

## 3. 操作步骤

### 第一步：数电直连通道配置（数电票场景）
1. 登录 EOP 运营平台，进入 **通道管理 $\rightarrow$ 税局通道配置**。
2. 选择目标租户与企业纳税人识别号。
3. 录入电子税务局实名办税员账号信息，或下发数电直连 API 认证凭据。
4. 点击【通道连通性测试】，确认税局返回联通成功状态码（HTTP 200 / Success）。

### 第二步：税控服务器/税控盘配置（传统税控场景）
1. 录入税控服务器 IP 地址、端口、安全证书及分机号。
2. 配置开票点编码、开票限额及默认税率规则。
3. 触发一张测试红字/蓝字发票请求（单据金额 0.01 元或沙箱模式），验证发票生成与回传闭环。

## 4. 常见问题排查
* **税局接口超时**：检查是否在税局每日对账切断时段；联系 [交付与开通异常报错速查表](./1.4.7%20交付与开通异常报错速查表.md)。
* **税盘证书过期**：指引客户登录税控盘客户端完成在线证书延期。
