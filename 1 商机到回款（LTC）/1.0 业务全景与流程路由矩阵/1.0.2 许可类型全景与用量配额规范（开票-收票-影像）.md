# 许可类型全景与用量配额规范

## 1. 许可类型全景定义

发票云许可（License）代表客户使用发票云产品功能的合法商业凭据，分为以下三类：

| 许可类型 | 核心用途 | 计费与商务要求 | 时长限制与风控 |
| :--- | :--- | :--- | :--- |
| **正式许可 (Official License)** | 客户生产环境正式上线运行 | 需签订正式商务合同并完成标准或特批提单出库 | 依据合同约定的服务周期（通常为1年/多年度订阅） |
| **临时 / 测试许可 (Trial/Test License)** | 售前方案验证、新客户开票联调、POC测试 | 免费申请，走云之家智能审批 | 单次最多 30~90 天，累计受天数上限管控，超期需走特批 |
| **伙伴演示许可 (Partner Demo License)** | 签约 ISV 及认证渠道伙伴进行系统联调与方案演示 | 伙伴准入认证后配额发放，不可商用 | 按伙伴合作协议年度评审重新授权 |

## 2. 三大功能模块用量配额规范

发票云交付的核心模块（开票、收票、影像）具有独立的用量核算与配额维度：

### 2.1 开票模块配额
* **核算单位**：开票张数包（年开票量包）+ 纳税人识别号数量（税号数）。
* **配额控制**：
  - 基础包内含基础税号数量与初始年开票量。
  - 超出后需走增购流程采购“加税号包”或“发票量加油包”。
  - 涉及数电直连通道或硬件税控服务器时，需额外核算通道月租或设备许可。

### 2.2 收票模块配额
* **核算单位**：发票查验量（次/年）+ 认证抵扣税号数。
* **配额控制**：
  - 包含基础收票查验量与底账库同步服务。
  - 用量耗尽后触发预警，需增购查验流量包。

### 2.3 影像模块配额
* **核算单位**：OCR 识别页数包 + 影像云存储空间（GB）。
* **配额控制**：
  - OCR 接口按成功识别解析的单据页数扣减。
  - 存储空间根据合同约定提供，超量需扩容。
