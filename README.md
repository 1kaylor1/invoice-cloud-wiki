# 发票云运营知识库

> 金蝶发票云运营团队内部知识库，覆盖 LTC（商机到回款）、MTR（生态伙伴管理）、MCR（客户信息管理）三大业务板块。

---

## 这是什么

本知识库沉淀发票云运营部门的业务操作规范、流程指引和常见问题解答，面向发票云运营团队、金蝶中国渠道销售及发票云自营渠道销售。

**核心用途：**
- 新同事快速上手业务流程
- 日常操作遇到问题时自助查阅
- 团队知识沉淀与传承

## 使用说明

- 文章分为两类：**runbook**（操作类，照着做）和 **explainer**（说明类，了解背景）
