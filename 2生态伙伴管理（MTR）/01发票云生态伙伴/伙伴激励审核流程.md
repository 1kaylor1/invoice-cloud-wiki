## 适用场景

本文面向**发票云运营管理部内部人员**，用于审核伙伴提交的生态订阅产品专项激励申请。

伙伴了解激励申请方式，请参见 [伙伴激励制度说明](./1.3伙伴支持-伙伴激励制度说明.md)。

## 审核前提

- 伙伴已按发文要求完成市场推广活动
- 伙伴已提交：激励申请表 + 活动发票 + 活动报告

## 审批链路

激励审批共四个节点，须按序完成：

1. **运营审批**（发票云运营管理部）
2. **财务审批**
3. **总经理审批**（少斌总，在云之家群【发票云激励发文内部审核沟通群】中进行）
4. **HR 备案**（金定）

## 操作步骤

### 第一步：核对申请材料

收到伙伴激励申请后，核对以下内容：

- 申请表填写是否完整，是否符合当期发文要求
- 活动发票是否为增值税发票，金额是否与申请一致
- 活动报告是否真实有效（含活动说明、照片等）

### 第二步：审批操作（同意或驳回）

**同意时：**

- 在审批系统点击「同意」
- **必须附备注**，格式：`符合XX激励，计算公式：[列出具体计算过程和金额]`

**驳回时：**

- **必须选择「智能退回」**，不能直接点「退回」
- 直接退回会导致流程异常，智能退回才能将申请正确退回至发起人

### 第三步：KBC 专项预算立项

激励申请通过运营审批后，在 KBC 系统发起专项预算立项（由财务操作）：

操作路径：KBC → 应用 → 专项预算项目 → 项目立项（财务）

**重要：立项名称使用「先进表彰」，不得出现「激励」字眼。**

### 第四步：申请开票

预算立项完成后，在 KBC 系统申请开具发票：

操作路径：KBC → 应收 → 新增 → 开票单

按激励金额填写开票信息并提交。

### 第五步：对公费用报销

开票完成后，发起对公费用报销：

操作路径：KBC → 应用 → 对公报销 → 对公报销单

填写报销信息，需附以下材料：
- 激励发文
- 激励申请表
- 内部激励审核记录截图
- 市场活动报告

提交审批。

### 第六步：完成财务审批及总经理审批

报销单提交后，依次经过财务审批和总经理（陈少斌）审批。总经理审批在云之家群【发票云激励发文内部审核沟通群】中进行。

### 第七步：HR 备案

审批完成后通知 HR（刘金定）备案。

## 关键注意事项

| 操作 | 要求 |
|------|------|
| 驳回操作 | 必须选「智能退回」，不能直接退回 |
| 同意备注 | 须注明符合XX激励及计算公式 |
| 预算立项名称 | 用「先进表彰」，不用「激励」 |
| 开票路径 | KBC → 应收 → 新增 → 开票单 |
| 报销路径 | KBC → 对公费用 → 报账付款 → 对公报销单 |

## 常见问题

**Q：为什么驳回时要选「智能退回」而不是直接退回？**

A：直接退回会导致审批流程异常，申请无法正确回到发起人处修改，须选「智能退回」才能保证流程正常流转。

**Q：预算立项为什么不能用「激励」字眼？**

A：KBC 系统预算立项有命名规范，激励类支出须以「先进表彰」命名，避免触发系统校验或合规问题。

**Q：激励审批涉及哪些系统？**

A：审批系统（飞书智能审批）、KBC 系统（立项、开票、报销）、云之家群（总经理审批）。
