## 说明

本目录记录发票云产品**出库后的交付操作**，即客户订单出库后，运营人员和客户完成产品激活/许可分配的完整流程。

**适用范围：**
- 标准订单出库后的产品交付
- 特批订单出库后的产品交付（流程与标准订单一致）
- 续费订单出库后的产品交付（流程与标准订单一致）

**不在本目录范围内：**
- 测试授权/试用产品的激活（见 [1.1.4 测试授权申请操作指引](../1.1 商机与售前/1.1.4测试授权申请操作指引（临时许可）/（0）自营渠道测试授权申请说明.md)）
- 订单申请和特批流程（见 [1.3.2 特批订单](../1.3 订单管理/1.3.2特批订单/)）

**核心原则：产品交付动作只和产品本身及部署方式有关，与订单类型无关。**

## 产品版本与部署方式说明

| 产品版本       | 支持部署方式 | 交付方式                                 |
| ---------- | ------ | ------------------------------------ |
| 开票/收票标准版   | 公有云    | 邮件激活链接 → 许可分配                        |
| 影像标准版      | 公有云    | 邮件直发登录地址（密码为账号后6位）                   |
| 影像标准版      | 私有云    | 邮件直发私有化许可文件                            |
| 开票/收票旗舰版   | 公有云    | 邮件激活链接 → 选择业务线 → 许可分配                |
| 开票/收票旗舰版   | 私有云    | 须先在云平台激活下载许可 → 邮件激活链接 → 选择业务线 → 许可分配 |
| 开票/收票星空旗舰版 | 公有云    | 同旗舰版公有云【待确认】                         |
| 开票/收票星空旗舰版 | 私有云    | 同旗舰版私有云【待确认】                         |

> **私有云特别注意：** 旗舰版私有云出库后，必须先登录云平台（https://cloud.kingdee.com/qy/home）进行激活下载许可并同步更新到MC平台，再进行发票云许可分配流程，否则将影响产品使用。
