## 说明

订单提交并收款确认后，系统自动完成出库流程，将产品许可分配给客户。出库可以通过系统自动发送邮件或运营人员手动操作两种方式完成。

## 出库触发方式

### 方式一：系统自动出库（正常情况）

财务在EOP系统确认收款后，系统自动执行：
1. 调用AWS生成产品许可
2. 生成激活码和激活密码
3. 自动发送出库交付邮件至客户联系邮箱
4. 订单状态变为**已出库**

客户收到邮件后，按邮件指引完成产品激活，详见[产品交付](../../2.4产品交付/)相关文档。

### 方式二：运营人员手动操作（异常处理）

如系统自动出库失败，运营人员需手动处理：

| 异常情况 | 处理操作 |
|---|---|
| 许可未分配（AWS调用失败） | EOP订单详情页 → 点击【去分配权益】手动触发 |
| 交付邮件未发送 | EOP订单详情页 → 点击【发送出库交付邮件】手动重发 |
| 激活码失效 | EOP订单详情页 → 点击【重新生成激活码】 |
| 授权邮件未发送 | EOP订单详情页 → 点击【重发授权邮件】 |
| 需要重新分配许可 | 点击【取消已分配权益】→ 再点击【去分配权益】 |

## 确认收款操作步骤

### 单笔收款

1. 在EOP订单详情页（待付款状态），点击【单笔付款】
2. 上传收款凭证（图片或PDF）
3. 填写收款金额和收款日期
4. 点击确认，系统自动触发出库流程

### 合并收款

1. 在订单列表中选择多个"待付款"订单
2. 点击【合并付款】
3. 上传收款凭证，填写合并收款金额
4. 确认后，所选订单统一完成收款确认

## 常见问题

**Q：收款确认后多久能出库？**
A：系统收款确认后立即自动触发出库流程，通常几分钟内客户即可收到邮件。如超过30分钟未出库，请检查邮件发送状态是否显示"等待手工处理"。

**Q：客户没收到出库邮件怎么办？**
A：在EOP订单详情页点击【发送出库交付邮件】手动重发；如仍有问题，联系售后热线 4009677223 或在线客服 https://tax.piaozone.com/sobot-web/home。
