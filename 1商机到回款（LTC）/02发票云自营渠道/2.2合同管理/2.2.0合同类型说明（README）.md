## 说明

发票云自营渠道合同分为两大类：标准合同和非标合同。合同类型在创建时选择，不同类型对应不同的审批流程和操作路径。

## 合同类型

| 合同类型 | 说明 | 适用场景 |
|---|---|---|
| 标准合同 | 标准化产品合同，走标准审批流程 | 常规新购、续费、加购 |
| 框架合同 | 框架协议，可关联多个子合同 | 大客户框架协议 |
| 非标合同 | 需特殊审批的定制合同，须额外上传审批附件 | 特殊定制场景 |
| 实施合同 | 项目实施类合同 | 有实施交付的项目 |

## 合同状态说明

合同从创建到完结会经历以下状态：

```
暂存 → 待审核 → 审核中 → 待生效 → 生效中 → 已完结
                              ↘ 已驳回（需修改后重新提交）
```

| 状态 | 说明 |
|---|---|
| 暂存 | 合同草稿，已保存但未提交 |
| 待审核 | 已提交，等待审核人处理 |
| 审核中 | 审核人已接单，正在审核 |
| 待生效 | 审核通过，等待电子签章完成 |
| 生效中 | 合同已生效，执行中 |
| 已完结 | 合同履行完毕 |
| 已驳回 | 审核不通过，需修改后重新提交 |
