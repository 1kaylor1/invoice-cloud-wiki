## 说明

本目录覆盖发票云自营渠道的测试授权（临时许可）申请流程，适用于发票云自营销售团队为客户申请产品试用。

## 与金蝶中国渠道的差异

| 产品 | 金蝶中国渠道 | 发票云自营渠道 |
|---|---|---|
| 开票标准版 | 智能审批 + 许可分配 + 全电配置 | 同金蝶中国渠道 |
| 收票标准版 | 智能审批 + 许可分配 | 同金蝶中国渠道 |
| 影像标准版 | 智能审批，邮件获取账号，60天 | 同金蝶中国渠道 |
| 开票旗舰版 | 仅私有云，KBC临时许可 + 智能审批 + 许可分配 | **公有云**：智能审批 + 许可分配 + 获取测试环境账号；**私有云**：同金蝶中国渠道 |
| 收票旗舰版 | 仅私有云，KBC临时许可 + 智能审批 + 许可分配 | **公有云**：智能审批 + 许可分配 + 获取测试环境账号；**私有云**：智能审批 + 许可分配 + 许可文件下载 |
| 影像旗舰版 | 仅私有云，KBC临时许可 + 智能审批 + 联系杨慧莉 | 仅私有云，智能审批 + 联系杨慧莉（**无需KBC临时许可**） |
