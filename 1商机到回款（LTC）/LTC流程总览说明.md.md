## 说明

LTC（Lead to Cash，商机到回款）是发票云核心业务流程，覆盖从商机识别到最终回款的完整链路。

发票云运营知识库中的 LTC 模块分为两套并行流程：

| 渠道 | 下单系统 | 合同类型 | 特批路径 |
|---|---|---|---|
| 金蝶中国渠道 | KBC | KBC 合同 / 第三方询价合同 | KBC + 云之家智能审批 |
| 发票云自营渠道 | EOP | 标准合同 / 非标合同 | 云之家智能审批 |

## 流程阶段

两个渠道均包含以下五个阶段：

```
商机与售前 → 合同管理 → 订单管理 → 产品交付 → 回款结算
```

### 1. 商机与售前

覆盖产品咨询、售前顾问预约、产品报价获取、测试授权申请四类场景。

- [金蝶中国渠道售前文章](./01金蝶中国渠道/1.1 商机与售前/)
- [发票云自营渠道售前文章](./02发票云自营渠道/2.1商机与售前/)

### 2. 合同管理

- **金蝶中国渠道**：KBC 合同由金蝶中国系统管理，发票云运营仅处理第三方询价合同。详见[合同管理说明](./01金蝶中国渠道/1.2 合同管理/READEME.md)。
- **发票云自营渠道**：含标准合同和非标合同两种类型，从创建、审批、变更到到期均有完整流程。详见[合同类型说明](./02发票云自营渠道/2.2合同管理/2.2.0合同类型说明（README）.md)。

### 3. 订单管理

订单分为标准订单和特批订单两类：

- **标准订单**：正常下单、出库、到期管理、退货流程
- **特批订单**：产品新购场景下提前开通、续费场景下延期特批

各渠道订单管理：
- [金蝶中国渠道订单分类说明](./01金蝶中国渠道/1.3 订单管理/1.3.0订单分类说明.md)
- [发票云自营渠道标准订单创建来源说明](./02发票云自营渠道/2.3订单管理/2.3.1标准订单/（1）标准订单创建来源说明.md)

### 4. 产品交付

产品出库后需完成许可分配，客户才能正式使用产品。交付方式按产品版本和部署方式分类：

| 产品版本 | 部署方式 | 交付特点 |
|---|---|---|
| 标准版（开票/收票） | 公有云 | 邮件链接完成授权激活 |
| 标准版（影像） | 公有云/私有云 | 邮件获取登录信息 |
| 旗舰版 | 公有云 | 邮件链接完成许可分配 |
| 旗舰版 | 私有云 | 须先登录 cloud.kingdee.com 激活，再完成许可分配 |
| 星空旗舰版 | 公有云/私有云 | 同旗舰版对应部署方式 |

## 两套渠道的关键差异

| 对比项 | 金蝶中国渠道 | 发票云自营渠道 |
|---|---|---|
| 下单系统 | KBC | EOP |
| 合同管理 | KBC 系统，发票云不介入 | EOP 系统，发票云全程管理 |
| 标准版测试授权 | 云之家智能审批 | 票省事小程序 |
| 旗舰版特批 | KBC + 云之家智能审批 | 仅云之家智能审批 |
| 旗舰版延期 | KBC 延期续签申请 | KBC 延期续签申请（同金蝶中国） |
| 退货处理 | 退货不退款 | 可退货退款 |
